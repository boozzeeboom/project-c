# T-SHIP-FIX05 — убрать двойной dt у мезия-тяги

> Тикет: `T-SHIP-FIX05` (P0, фаза B). Дата: 2026-09-18. Статус: **ИСПРАВЛЕНО (код + дока)**.
> Тесты — за пользователем (кейсы также в `docs/dev/global_needtotest/SHIP_TESTS.md`).

## Перепроверка (до фикса, поиском по диску — ПОДТВЕРЖДЕНО)

- `ShipController.cs:2086` (было): `_rb.AddForce(transform.forward * meziyThrustForce * dt, ForceMode.Force)`.
  `ForceMode.Force` уже интегрирует силу за `fixedDeltaTime` внутри физики → лишний `* dt`
  давал зависимость `dt^2` (тяга ~в 50 раз слабее при `fixedDeltaTime=0.02`).
- Конвенция файла: все остальные `AddForce` (`:1625` thrust, `:1636` gravity, `:1642` lift,
  `:2150`, `:2208/:2261` wind) — `ForceMode.Force` БЕЗ `* dt`. Торки мезии (PITCH/ROLL/YAW,
  тот же метод) — тоже без `dt`. Строка была единственным исключением.
- После фикса в файле не осталось ни одного `* dt, ForceMode` (проверено поиском).
- Сила вырастет ×50: `meziyForce` в ассетах 500–1000 (4 модуля). Если на плей-тесте окажется
  сильно/слабо — крутить `meziyForce` в SO (баланс, НЕ этот тикет, поведение физики теперь честное).

- `Assets/_Project/Scripts/Player/ShipController.cs` (+3/−1): убран `* dt` + коммент-причина.
