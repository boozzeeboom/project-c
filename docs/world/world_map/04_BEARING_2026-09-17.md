# Пеленг на метку в HUD (слой 3)

**Дата:** 2026-09-17
**Статус:** ✅ Реализовано
**Код:** `ShipHudController` — TGT-строка в K4 ENV
**Концепт:** `00_CHART_CONCEPT_2026-09-17.md §3 (слой 3)`

## 1. Поведение

Выбрал метку на карте (M) → в HUD корабля под HDG-строкой появляется янтарная
строка: `→ Штормовой кар… 042° NE • 1.2 км` (имя до 14 символов, пеленг через
`WorldNorth`, дистанция м/км). Снял выбор / удалил метку — строка прячется
(`display: None`, места не занимает).

## 2. Честность

Пеленг считается только до своей выбранной метки. На неизведанное не ведём:
без метки вести некуда — это и есть морская логика (сначала отметь, потом иди).

## 3. FO и данные

Пеленг — из живых позиций каждый кадр (корабль + метка едут одним сдвигом),
хуков не надо. Менеджер ищется один раз (`FindAnyObjectByType`, кэш),
`SelectedId`/`TryGetMark` уже были готовы с прошлого слоя.
