# Подключаемые мозги толпы (crowd_brains) — навигация

> **Статус:** теория / дизайн, кода нет. Только анализ.
> **Вопрос:** корабль на 300 человек (наполнить хотя бы наполовину — ~150), города на тысячи. Клиент видит многих, сервер не должен обрабатывать всех. Пинок любому → сдачи. Разговор с любым → он становится «героем».
> **Ответ коротко:** толпа живёт на клиенте без сети и AI. Сервер хранит только ростер (кто существует) + пулы мозгов (кто сейчас думает). Событие игрока (удар / E-разговор) **промоутит** 1 + 2–7 соседей во временные «герои» с лизой (арендой) слота. По окончании — **демotion** обратно в толпу. Остальные 140+ остаются клиентской декорацией.

## Глоссарий (используется во всех файлах)

- **Толпа (crowd)** — визуальные люди на клиенте. Нет `NetworkObject`, нет `NpcBrain`, нет серверного тика. Живут на якорях/петлях.
- **Ростер (roster)** — серверная таблица «кто существует»: `crowdId → (где приписан, жив/мёртв, отношение, обида)`. Это данные, не GameObject. Десятки байт на человека.
- **Герой (hero)** — человек, у которого прямо сейчас есть серверное состояние: бой, диалоговая сессия, квест. Дорогой. Их единицы.
- **Мозг (brain)** — право думать: слот серверного тика (`NpcBrain`-эквивалент) или диалоговой сессии (`QuestWorld`-сессия). Выдаётся из пула.
- **HitProxy** — «меня можно ударить»: минимальная реализация `IDamageTarget` на сервере как чистые данные (без GameObject). Принимает урон, решает «терпеть / повышать».
- **Промоут (promotion)** — перевод `толпа → герой`: сервер выделяет слот из пула, привязывает мозг/сессию к `crowdId`, рассылает дельту клиентам-наблюдателям.
- **Лизa (lease)** — аренда слота с TTL и условиями продления (бой идёт / диалог открыт). Нет продления → **демotion**.
- **Демotion (demotion)** — возврат `герой → толпа`: слот освобождён, сервер хранит только итог (HP, обида, отношение, квест-флаг), визуал снова клиентский.
- **Бюджет** — жёсткий кап одновременных героев на зону/игрока (например, 6–8 бойцов, 1–2 диалога на игрока). Превышение → очередь/фолбэк, а не лаги.
- **Наблюдатель (observer)** — клиент, которому видна зона. Дельты героев шлются только наблюдателям, не всему миру.

## TL;DR теории (для тех, кому лень читать 8 файлов)

1. **Клиент рисует 150, сервер тикает 6–10.** Остальное — ростер + клиентские петли. Это единственный способ уложиться в NGO-трафик (~75 КБ/с на 150 трансформов — уже смерть), серверный NavMesh O(n²) и 150 скинов в URP.
2. **У каждого видимого есть ID и HP на сервере, но нет тика.** Пинок идёт через тот же `CombatServer.ResolveAttack`, потому что `IDamageTarget` — чистый интерфейс (`Scripts/Combat/Core/IDamageTarget.cs`), ему не нужен GameObject. Серверная запись толпы может реализовать его как struct/class.
3. **Дерутся только повышенные.** Первый удар + проверка пула → 1 обидчик-цель + 2–7 соседей по `alarmHearingRadius` получают мозг. Остальные — `ForceFlee`/cower/зов охраны (уже есть `NpcSocialBrain`: `ForceFlee`, `Surrendered`, `isGuard`, `grudge`).
4. **Говорить можно с любым, герой — на время.** Разговор уже устроен как серверная сессия без `NetworkObject`: `NpcController` — обычный `MonoBehaviour` (`Quests/NpcController.cs`), `QuestServer.RequestTalkToNpcRpc` проверяет дистанцию через `NpcController.Find(npcId)` + `IsWithinDistance`, дерево берётся из `questDatabase.GetNpc(npcId)` или строится fallback (`QuestServer.cs:491–568`). Значит, толпе достаточно выдать стабильный `npcId` + резолвер позиции, а герою-в-аренде — сессию и, при нужде, сгенерированное дерево. Закрыл диалог → сессия закрыта, «геройство» истекло (TTL «на день» = лиза с продлением, см. `03`).
5. **Корабль везёт толпу бесплатно.** Толпа — дети `ShipRoot` в локальных координатах. Корабль летит/ребейзится — толпа едет без сети и без Floating Origin-участия. Повышенные бойцы на палубе дерутся in-place, без NavMesh-погонь в тесноте.
6. **Всё, что не влезло в бюджет, — вежливый отказ, а не лаг.** Нет слота → убегание/капитуляция/очередь. Это дизайн, а не баг (как у GTA: бьют 2, бегут 20, приезжает полиция).

## Что здесь НЕ утверждается

- Не утверждается, что 150 полных `NpcBrain` возможны. Наоборот: они невозможны, и этот пакет — про то, как их избежать.
- Не утверждается готовый код. Псевдо-схемы в документах — это спецификация поведения, не diff.
- Числа бюджетов (6–8 бойцов, 40–60 видимых, AOI 80–120м) — стартовые гипотезы для калибровки Profiler'ом, а не константы.
