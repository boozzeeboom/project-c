# T-PAROM-22 — защита от падений с парома (дизайн)

> Статус: дизайн. База: ship-proximity rescue (`TryResolveShipRescuePosition`),
> `TeleportToClientRpc` (контроллер off/on + сброс скорости + SyncTransforms),
> T-PAROM-21 (`GetBoardingPoint`, live-точка крыши).

## 1. Цель

Соскользнул/столкнули с кабинки на ходу — возврат на крышу вместо 20-секундного
падения и респавна далеко. Только недавняя опора (окно), только та же ветка,
только вверх. Сервер-авторитетно (как весь `PlayerRespawnTracker`).

## 2. Условия спасения (все сразу, каждый тик сервера)

- С момента схода с платформы (`detach`) прошло < окна (дефолт 8 с).
- Ветка жива (`IsSpawned`), cooldown спасения истёк (дефолт 20 с).
- Игрок в воздухе (`!isGrounded`) и падает (`vy < 1`), ниже крыши более
  чем на порог (дефолт 4 м — хопы 0.3 м не триггерят) и в радиусе (дефолт 12 м)
  от кабинки по горизонтали.
- Дальше/позже/на земле — обычный death-respawn, не трогаем.

## 3. Действие

`TeleportToClientRpc(boardingPoint)` (существующий: toggling контроллера,
сброс скорости, SyncTransforms) + сброс fall-таймера + старт cooldown.
Параметры в инспекторе: окно, порог падения, радиус, cooldown.

## 4. Реализация (без owner-состояния!)

След полёта на owner-стороне (`_currentPlatform`) НЕ пишем: dedicated-сервер
его не видит (carry owner-only), rescue бы не работал для remote-клиентов.
Вместо этого чисто геометрическая проверка server-side (позиции
реплицированы): скорость падения считается по истории Y в самом трекере
(`_velocity` owner-side — stale на сервере). Параметры в инспекторе:
окно не нужно (вместо него диапазон падения + cooldown).

## 5. Не входит

- Намеренный спрыг в сторону: в радиусе вернёт (безопасно > свобода, v1).
- NPC на пароме: тем же путём позже.
- Смерть/урон от падения: без изменений.

## 6. Проверка (пользователь)

1. Console → 0 errors.
2. На ходу спрыгнуть/столкнуться с крыши вниз: подхват обратно на крышу
   (лог rescue), без смерти, падение не дольше ~2 с.
3. Упасть далеко в стороне от трассы: обычный респаун (rescue не стреляет).
4. Полежать на земле под трассой: rescue не стреляет (grounded).
