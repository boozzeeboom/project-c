# Анализ v1 — DeepSeek за Нулей против двух ИИ

| # | Победитель | Причина | Ходов | Смертей Линейного |
|---|---|---|---|---:|
| 701 | Плюсы (ИИ) | king | 31 | 1 |

**0 побед / 1 ничья / 2 поражения.**

## Что делал DeepSeek

| Метрика | DeepSeek (Нули) |
|---|---:|
| Действий | 47 |
| **Ходов** | **0** |
| Поддержек | 47 |
| Пустых поддержек | 13 |
| Center ticks | 0 |
| Max hold | 0 |
| Осцилляций | 0 |

Он **вообще не двигал нулей**: только поддержки, из них 13 — повтор уже стоящей цели. Центр не оспаривался, `max hold = 0`.

## Причина: ошибка harness’а, а не только модели

В арене для Нулей список действий был отсортирован «поддержки первыми», а в промпт попадали первые 16 действий. У Нулей много поддержек, поэтому **все 16 были поддержками — ни одного хода модель не видела**.

Это нечестный тест доктрины: модель физически не могла пойти Скитальцем к воротам/Ц. Результат v1 нельзя использовать как оценку промпта.

## Вывод

- Доктрина Нулей **не проверена**: нужен исправленный список действий (ходы + поддержки).
- Исправление: показывать до 8 ходов (приоритет — ворота/«Ц») и до 8 поддержек, а не «все поддержки первыми».
- Также добавить в доктрину явный запрет «поддержка вместо гонки за Ц» и проверку, что в списке есть ходы.
