## 3. Реестры — вход для расстановки префабов

`03_DOORS/registries/doors_registry_<чанк>.csv`, 22 файла (BASE без дверей).

| Колонка | Смысл |
|---|---|
| `chunk` | чанк (например `S9_TRD-N_P1_28H`) |
| `door` | имя объекта: `<исходное имя>_<W>x<H>_X` (X = сторона петли не определена) |
| `pos_x, pos_y, pos_z` | **мировая** позиция пивота (низ по центру двери) |
| `rot_y` | ⚠️ **не использовать для ориентации**: у 2 648 из 3 038 дверей там `180°` — наследованный поворот корня города, а не направление стены. Реальное направление = по мировому AABB (см. `03_MASS_PLACEMENT.md` §4) |
| `w, h` | фактические ширина (max горизонтали) и высота, метры |
| `active` | сейчас `False` (двери выключены) |
| `verts, tris` | размер меша двери |

Дополнительно: `data/doors_manifest.csv` — 3 004 исходные двери (пивоты из Blender, до пересборки).

* В батчах местами лежат **3–5 см** бронзовые винтики/цилиндры и **мебельные ручки** рядом с дверями
  (это не двери; проверено аудитом `_work/audit_batch_islands.py`).

  для них нужен отдельный тип префаба «ворота/парадные».
