## 2. Гейты фаз

**Фаза 1 — чистка источника** (см. `01_INVENTORY_AND_CLEANUP.md` §5)
- [ ] `HAZE_MASS` удалён, `S6_NQ` без объектов за ±900 м, `S7_BIG` без сирот, `M_WOOD_DARK` на месте
- [ ] габарит города ≈ 2 000 × 100 × 2 000 м

**Фаза 2 — блоки** (см. `02_BLOCKS_AND_GEOMETRY.md` §6)
- [ ] 20–60 блоков, ≤ 1 500 объектов, треугольники сохранены (±1 %), ≤ 65 535 вершин на меш
- [ ] таблица «блок → меши → треугольники → габарит → материалы» заполнена

**Фаза 3 — сборка** (см. `03_UNITY_ASSEMBLY.md` §7)
- [ ] корень `PRIMUM` под `WorldRoot_0_0`, (0,0,0), масштаб 1, слой `PRIMUM`
- [ ] рендереров города ≤ 400, draw calls ≤ 120, у каждого блока коллайдер
- [ ] скрытие города тумблером слоя работает; редактор не тормозит

**Фаза 4 — дальность** (см. `04_LOD_AND_DISTANCE.md` §6)
- [ ] 0.5 км — полный город, 5–10 км — HLOD, 20–80 км — 1–2 draw calls
- [ ] ночь: силуэт + огни читаются сквозь туман

**Фаза 5 — FO/сеть/геймплей** (см. `05_FO_NETWORK_AND_GAMEPLAY.md` §6)
- [ ] F8/F9 с городом: 0 errors, город едет
- [ ] каждый `NetworkObject` города — маркер + каталог + digest
- [ ] NavMesh: маршрут порт → площадь → дом → 2 этаж проходим

## 3. Ручные проверки (выполняет пользователь; агент Play Mode не запускает)

1. Play Mode: персонаж стоит на площади и на крышах, не проваливается; ходит по улицам и лестницам.
2. Три пресета ESC-меню «Видео → Дальность прорисовки» (Near/Medium/Far): город и террейн ведут себя
   предсказуемо, LOD-переходы без «попов».
3. Кадры с одной точки на 0.5 / 5 / 20 км (3 пресета × 3 дистанции) — приложить к `ITERATIONS.md`.
4. Профайлер: draw calls, треугольники, память до/после города; отсутствие пиков GC.
5. F8/F9 из точки в городе и из точки в 30 км; второй клиент (если поднимается) видит город там же.
6. Ночной вид: силуэт и огни, поведение тумана.

## 4. Откат (rollback)

| Что откатываем | Как |
|---|---|
| FBX-блоки/чанки | исходные 18 чанков и `_deliver/` остаются в проекте Blender; перевыгрузка по акту 115 |
| Префаб города | бэкап прежнего префаба лежал в `%TEMP%\primum_unity_backup\PRIMUM_CITY.prefab.bak` (до пересборки) |
| Сцена | перед каждой фазой — коммит/бэкап `WorldScene_0_0.unity`; город снимается одним корнем `PRIMUM` |
| Слои | `PRIMUM` (слот 8) — при отказе просто переименовать/очистить слот |
| Комбинированные меши | `Assets/_Project/Generated/` — удаляются, пересобираются из FBX тулзой |

## 5. Риски и как их видим заранее

| Риск | Признак | Что делаем |
|---|---|---|
| Контент вне корня сцены | после F8 город «отстал» от мира | перенести под `WorldRoot_0_0` |
| `NetworkObject` без регистрации | Host падает: `uncontrolled_network_source_before_native_sweep` | прогнать bake-каталог по 09S |
| Масштаб/единицы FBX | модель в 100× больше или меньше | `useFileScale=true`, `globalScale=1`, сверка габаритов |
| Плоские коллайдеры/палубы | Rigidbody и корабли проваливаются | `BuildSettlementColliders`, `Мин. толщина 0.5` |
| Static-флаги на городе | после rebase батчинг/occlusion ломается | не помечать static |
| Гиганты в источнике | габарит 1 000+ м, импостор и LOD считаются неверно | фаза 1 (чистка) |
| Динамический сетевой спавн | объекты не появляются | пока `NetworkPrefabsList` не назначен — только scene-placed |
