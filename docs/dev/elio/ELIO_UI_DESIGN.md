# Эльо — дизайн интерфейса (3D/2D)

## 1. Анализ игры

### 1.1. Сущности
- **3 фракции:** Плюсы (синие), Минусы (красные), Нули (серые).
- **Доска:** 64 клетки (3 поля по 19 + 6 спорных + 1 «Ц»).
- **Фигуры:** 6 типов у военных, 5 у Нулей, пешки в тест-режимах.
- **Режимы хода:** Цикл, Стрелка, Передача.
- **Типы игры:** Основной (гибель Линейного), Длинный (выбывание).
- **Победа:** гибель Линейного / удержание «Ц» 1–5 следующих собственных ходов (стандарт 3, победа в начале 4-го хода держателя) / лимит 90.

### 1.2. Ключевые UI-элементы
1. **Заголовок + подзаголовок** — название, краткое описание.
2. **Панель режима игры** — селекторы: порядок хода, направление цикла, пешки, тип игры, удержание 1–5, лимит, причина.
3. **Панель статуса** — текущий ход (цвет), hold-бары и обратный отсчёт до победы у каждой фракции и над доской, счётчики фигур, game over.
4. **Панель клетки** — информация о выбранной клетке/фигуре (код, q,r, фигура, статус нуля).
5. **Панель управления** — Новая игра, Ход ИИ, Авто-игра, Стоп, Экспорт, Импорт, Replay.
6. **Лог ходов** — текстовый лог, автопрокрутка.
7. **Replay** — Start/Step/Play All, позиция.
8. **Импорт лога** — textarea + кнопка.

### 1.3. Взаимодействие
- Клик по своей фигуре → яркие пульсирующие маркеры → клик по маркеру или любому месту целевого гекса (в 2D и 3D).
- Наведение на фигуру → компактный tooltip с типом, фракцией, клеткой, статусом и описанием.
- Поддержка: клик по нулю → клик по цели щита.
- Оттеснение: как ход (displace).
- Выделение: масштаб фигуры + подсветка.

## 2. Дизайн-система

### 2.1. Цвета
- Фон: #1a1a2e (тёмно-синий).
- Панели: rgba(35,35,74,0.9) с blur.
- Золото: #c9a227 (акценты, заголовки).
- Плюсы: #5b9bd5 (синий).
- Минусы: #e05a5a (красный).
- Нули: #9aa0a6 (серый).
- Текст: #e8e8f0.
- Ошибки: #ff4444.
- Успех: #4caf50.

### 2.2. Типографика
- Заголовки: Georgia/serif, gold.
- Основной текст: Segoe UI, 13px.
- Лог: monospace, 11px.

### 2.3. Компоненты
- **Панель (Card):** полупрозрачный фон, скруглённые углы, тень.
- **Кнопка:** золотая (primary), серая (secondary), с hover-эффектом.
- **Тост (Toast):** всплывающее уведомление справа внизу, 3 сек, анимация появления/исчезновения.
- **Попап (Modal):** полупрозрачный оверлей + карточка с описанием/подтверждением.
- **Переключатель 2D/3D:** toggle в шапке, с анимацией перехода.
- **Подсветка ходов:** сферы с анимацией пульсации.

### 2.4. Анимации
- Появление панелей: fade-in + slide-up.
- Тосты: slide-in from right.
- Переход 2D↔3D: fade-out/fade-in с поворотом камеры.
- Подсветка: пульсация opacity.
- Ход фигуры: lerp позиции + scale.

## 3. Переключение 2D/3D

### 3.1. Архитектура
- Один HTML-файл с двумя режимами: 2D (SVG) и 3D (Three.js).
- Переключатель в шапке: "2D / 3D".
- При переключении:
  - 2D: показать SVG-доску, скрыть canvas.
  - 3D: показать canvas, скрыть SVG.
  - Состояние игры (state) общее — не сбрасывается.
  - Позиции фигур синхронизируются.

### 3.2. Визуальный переход
- Fade-out текущего режима (300ms).
- Поворот камеры (в 3D) или перестройка (в 2D).
- Fade-in нового режима (300ms).

## 4. Тосты и попапы

### 4.1. Тосты
- Типы: info, success, warning, error.
- Позиция: правый нижний угол.
- Автоскрытие: 3 сек.
- Очередь: до 3 одновременно.

### 4.2. Попапы
- Подтверждение (новая игра, импорт).
- Информация (правила, описание режима).
- Оверлей: полупрозрачный чёрный фон.
