# Terrain_0_0 — единый террейн WorldScene_0_0

Полный террейн сцены 80×80 км вместо отдельных low-poly массивов. База Y=600, геройские пики до 5000, хребты до ~3300, поселения открыты (зазор ≥170 м, закопанных объектов — 0).

## Руины низин (T-TERR-02)

Генеративные «раскуроченные» строения без моделинга: 5 мешей строятся кодом из джиттерованных боксов (стена с рваным верхом, прислонённая плита, торчащая балка, блок, щебень; наклон запечён, pivot = min.y). 60 хамлетов × 6–12 шт в низинах 650–1050 м (склон <0.35, вдали от поселений/массивов). Высота — точным семплом террейна в точке, заглубление 0.3 + 12% высоты меша.

Перф: 2 материала с GPU Instancing → ~5–7 draw calls на все 496; тени выкл, коллайдеров нет, `isStatic=false` (не ломает батчинг при сдвиге мира).

## Floating Origin

`Terrain_0_0` и `RuinsValleys` — дети `WorldRoot_0_0` (🟢 едут бесплатно; heightmap в локальных координатах, хуков не надо). Проверка: F8 → `runtimeRebase.Completed` + 0 errors. Не кэшировать мировые высоты без хука; сейвы — паттерн `ShipPositionServer` (мировые + кумулятив).

## Как перегенерить (порядок важен!)

1. База (fbm-холмы 600–1450) → 2. герои → 3. цепи → 4. доводка вершин точно (AddBump σ героя) → 5. отроги адаптивно (только `diff>0`, иначе двойной учёт!) → 6. clamp → 7. SetHeights → 8. SetAlphamaps.
9. Точечные правки — хирургически `GetHeights/SetHeights` по bbox, НЕ полной регенерацией.

## Запреты (кровью из ITERATIONS)

- ❌ Потолки `min(h, ceiling)` — дают плоские меза-плато. Открытость — fitted-склонами, рерутом цепей (≥3 км от поселений), штампом старой поверхности.
- ❌ Пики по origin инстансов — только по истинным вершинам (max-vertex world).
- ❌ Цепи ближе 3 км к поселениям (σ1500 задушит зазор).
- ❌ Доводка вершин ДО отрогов / снятие склонов масками — двойной учёт высот.
- ⚠️ `TerrainData.GetHeight/GetInterpolatedHeight` возвращают ЕДИНИЦЫ `size.y`, не 0..1!
- ⚠️ Текстуры террейна — только вне `*Textures*` (иначе не попадут в git).
