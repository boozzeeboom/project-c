# lore_summary_context — канон мира для арт-генерации

**Назначение:** собрать в одном месте лор, стиль и палитру Project C: The Clouds, чтобы генерировать изображения (города, корабли, предметы, персонажи — фермерские и городские, бедные и богатые) **в одной стилистике** и в согласии с тем, что уже есть в Unity.

**Обновлено:** 2026-10-24 · **Автор:** сборка по документам проекта и конспекту книги.

## Как пользоваться

1. Открыть `ART_STYLE_MANIFEST.md` §1 (формула стиля) и §2 (палитра) — это ядро.
2. Взять §10.1 (стилевой блок) + §10.2 (негативный) и добавить §10.3–§10.7 (subject под нужный тип арта).
3. Прогнать результат по чек-листу §11.
4. Если чего-то не хватило — смотреть §12 «недокументировано» и не выдумывать молча.

## Канон в шесть строк

1. **Стиль:** стимпанк + дизельпанк + пост-апокалипсис в эстетике западного sci-fi-комикса (контур, мягкие градиенты, объёмный свет, Ghibli-облака).
2. **Мир:** 2090 год, человечество живёт **над облаками** на горных пиках; внизу — фиолетовая ядовитая **Завеса** (`#2d1b4e`), подниматься из которой невозможно.
3. **Технологии:** антигравий (голубое свечение `#4fc3f7`), мезий (зелёное `#66bb6a`), МАГ-генераторы, ветровые лопасти, пар. **Магии нет.**
4. **Материалы:** гранит, кирпич, клёпаная сталь, ржавчина, бронза/латунь, дерево, стекло, ткань. В игре 95 % поверхностей — процедурные, без текстур: фактура и износ, а не фотография.
5. **Люди:** Новое Правительство (чёрная форма) → гильдейцы (5 цветов) → торговцы → фермеры → потеряшки/алиенумы; враждебные — бандиты и ржавые пираты. Богатство читается материалом и точностью, бедность — доской и заплатами.
6. **Камера:** тёплое сверху, холодное снизу, закат всегда, города подавляюще многоярусные, корабли — баржи, не истребители.

## Известные ограничения сбора

- **RAG-БД книги недоступна** (`192.168.31.227:5432`, `book_chunks`, 1465 чанков): `Connection timed out (0x274C/10060)` на 2026-10-24. Полный текст книги не цитировался — только конспект `WORLD_LORE_BOOK.md`. Когда БД поднимется, манифест стоит обогатить прямыми цитатами (особенно про быт, одежду, интерьеры).
- Часть визуальных решений (азиатский колорит Примума, дизайн одежды, внешний вид кораблей и оружия) **в репозитории не зафиксирована** — см. §12 манифеста.
