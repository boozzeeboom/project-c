# Эльо — проект (v1.3c)

> MMO-sandbox / настольная игра по книге «Интеграл Пьявица». Это **прототип правил и движка**, не Unity-сцена.

## Статус

- **Правила:** v1.3, 6 типов у военных, 10 фигур, 30 очков; режимы «Цикл» / «Стрелка» / «Передача»; типы игры «Основной» / «Длинный».
- **Движок:** `elio_engine.js` v1.3 — pass-режим, фикс инертного «Ц», лимит 90.
- **ИИ:** `elio_ai.js` v1.3c — без пустых поддержек и осцилляций, умеренный king-hunt.
- **Прототип:** `elio_game_v51.html` (браузер, без сборки).
- **Эталон:** «Стрелка + Длинный»; на двух 400-сидах — **35.9 / 33.4 / 29.3**, 87 выбываний, средняя 37.7. Первый ход в «Стрелке» случайный.
- **Передача хода:** 400 партий (канон `random`) — **32.4 / 35.8 / 31.2**, средняя 29.3, 43 убийства короля.
- **15 фигур (пешки):** тест-вариант, 200×6 — Нули 36.5–67 %, пока не сбалансирован; каноном не является.
- **10+1 пешка в C1:** тест-вариант, 200×6 — в «Стрелке+Длинном» Нули 42.5 %, в цикле 67 %; не канон. 10 фигур остаются эталоном.

## Быстрый старт

1. Открыть `elio_game_v51.html` в браузере.
2. Выбрать порядок хода: **Цикл / Стрелка / Передача**.
3. Выбрать тип игры: **Основной** (гибель Линейного = победа) или **Длинный** (выбывание).
4. В «Передаче» селектор **«Передать»** показывает двух легальных получателей; ИИ/авто выбирает случайного.
5. Кнопки: ход ИИ, авто-игра, экспорт/импорт JSON, replay.
