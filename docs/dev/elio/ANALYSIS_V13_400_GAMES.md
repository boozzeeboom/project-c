## 1. Главное: новые фигуры работают

- **Линкор** (любая дистанция по прямой, тяжёлый) и **Бомбардир** (прыжок 2–3 через фигуры, лёгкий) дали реальные дальние угрозы Линейному.

- В **Стрелке + Длинный**: **25 выбываний** — гибель Линейного теперь случается, и длинный режим перестал быть копией основного.

**Гипотеза пользователя подтверждена:** длинноходные фигуры делают короля уязвимым. Без них король был декоративен (0/400), с ними — 3–25 % в зависимости от режима.

- **34 / 31 / 34 / 1** — ровно по одной трети в первом 100-партийном сэмпле.

> **Уточнение по 400 партиям:** «34 / 31 / 34» — свойство 100-партийного промежуточного прогона. После фикса инертного «Ц» на двух 400-сидах v1.3c даёт **35.1 / 30.2 / 33.0**. Прежние 39 / 34.6 / 26.4 были искажены багом; подробнее — раздел 7.

## 4. Король и «шах»

- В **Стрелке + Основной** 25 % побед убийством Линейного — это много. Если это не нравится, есть два пути:
  1. **«Шах»** — запрет оставлять Линейного под боем; это уменьшит случайные убийства и сделает короля «настоящим».
  2. **Длинный режим** — убийство не заканчивает партию, а выбивает фракцию; в Стрелке+Длинном это даёт баланс 34/31/34.
- В **Цикле** 3 % — «шах» не нужен.
- Рекомендация: **не вводить «шах» в длинном режиме** (там убийство — часть игры); в основном — либо оставить 25 %, либо ввести «шах» после плейтеста.

## 7. AI v1.3c — корректировки и фикс движка (400 партий)

По итогам разбора LLM-матчей в ИИ внесены три правки:

1. **Запрет пустых поддержек.** Кандидат `support` на уже стоящую цель больше не рассматривается.
2. **Анти-осцилляция.** Ход, возвращающий фигуру на клетку, с которой она только что ушла, получает штраф (кроме взятия, «Ц» и ворот).
3. **Длинный режим: не бросать накопленный «Ц».** Если фракция уже удерживает центр (hold ≥ 1), ИИ не снимает фигуру с «Ц» ради автоматического убийства Линейного; на первом входе охота за Линейным разрешена.

### 7.0. Важный фикс движка

- В Длинном режиме **инертная фигура выбывшей фракции на «Ц» больше не удерживает центр** и не приносит победу по лимиту. Раньше выбывшая фракция могла «фантомно» выиграть удержанием.
- Все 400-партийные числа ниже пересчитаны после фикса. Прежние 39 / 34.6 / 26.4 были искажены этим багом.

### 7.1. Баланс (Стрелка + Длинный, 400 партий)

|---|---|---|---|

- После фикса бага «Плюсы первые» дают **35.1 / 30.2 / 33.0** — значительно ровнее, чем казалось раньше.
- **Случайный первый ход не помогает:** 36.4 / 32.4 / 30.3, разрыв больше. Решение: оставить первый ход у Плюсов, как в исходных правилах.
- Главный источник прежнего «перекоса Плюсов» — не первый ход, а баг с инертным «Ц».

### 7.4. Эксперимент со случайным первым ходом — откатан

- До фикса бага казалось, что случайный первый ход лечит перекос (35.5 / 33.8 / 30.3 против 39 / 34.8 / 26.3), и он был внедрён.
- После фикса корректные числа: **35.1 / 30.2 / 33.0** (Плюсы первые) против **36.4 / 32.4 / 30.3** (случайный). Случайный старт **хуже**, поэтому изменение откатано.
- Это хороший пример конфаунда: баг делал Плюсов «сильнее», а рандомизация первого хода маскировала симптом.
