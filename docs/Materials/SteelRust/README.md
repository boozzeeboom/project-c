# SteelRust — сталь с процедурной ржавчиной на стыках

> Статус: **PROTOTYPE v1 создан, визуально НЕ проверен (NOT RUN).**
> Шейдер `Assets/_Project/Shaders/ProceduralSteel.shader`
> (`ProjectC/ProceduralSteel`), пресеты `Assets/_Project/Materials/Steel/`
> (`M_PC_Steel_Clean`, `M_PC_Steel_Rusted`, `M_PC_Steel_Dark`).
> Компиляция: Console → 0 shader errors (04.10.2026, проверено через unity-mcp).
> Визуал, F8/F9, bake Pointiness — за пользователем.

## 1. Что это и зачем

Базовый конструкционный материал игры: корпуса кораблей, станции, доки,
фермы, трубы, руины. Один шейдер `ProjectC/ProceduralSteel`, пресеты-материалы
(`M_PC_Steel_Clean`, `M_PC_Steel_Rusted`, `M_PC_Steel_Dark` и т.д.).
Ржавчина сидит **в стыках, швах и вогнутых углах** (там, где стоит вода
и облезает покрытие), а выпуклые кромки — наоборот, **зачищены до металла**
(потёртость от рук/ударов). Это физически правдоподобно и визуально читается.

## 2. Короткий вердикт (v5: проверено глазами, деривативы мертвы здесь)

**Пиксельные деривативы (`fwidth`) в этом проекте слепы к границам
треугольников — доказано серией `ProjectC/DiagDeriv`-тестов со скриншотами:**
`ddx`/`ddy`/`cross` живы (красно-зелёный куб), `normalize` корректен (плоские
цвета граней), а `fwidth()` попиксельно-постоянного поля возвращает 0 везде,
включая рёбра 90° и силуэты. Деривативы удалены из шейдера (v5).

**Рабочий путь: печёный G + силуэтный рим.** `EdgeMaskBaker` считает
двугранные углы из координат (проверено: 384 verts → 98 точек, 96 sharp
edges, Gmax=0.47/Gavg=0.32 на скошенном кубе) — это и есть «процедуральное
решение через координаты», аналог Blender Pointiness (который тоже считается
из геометрии, причём повершинно). Шейдер даёт полосе ширину (`_EdgeWidth`),
рваность шумом (`_EdgeNoise`) и назначаемые эффекты (`_EdgeRust`,
`_EdgeWear`); рим (`_EdgeRim`) — дешёвая читаемость силуэта. Проверено
скриншотами: белая полоса по рёбрам в Edge Band + ржавчина/блики в финале.
Без текстур, без screen-space буферов.

**Ограничение, доказанное на практике:** вершинным данным нужна плотность.
На жёстком 24-вершинном примитиве все вершины угловые → G=1 везде → бейк
бесполезен. Рецепт: фаски/сабдив (ProBuilder: bevel + subdivide, оба шага
через unity-mcp) + бейк. Игровые ассеты из Blender и так идут с фасками.

## 3. Как работает (слои, порядок важен)

```
0. КАНАЛ ГРАНЕЙ (назначаемая полоса, v6/v7):
   edgeBand = max(печёный G [cut], кривизна curv×gain) × рваность × мастер.
   Два домена: bake = ЖЁСТКИЕ рёбра (сплит-вершины, фаски), curv = ПЛАВНЫЕ
   изгибы (усреднённые нормали). curv=|dN|/|dP| в 1/м — стабильна (сокращается
   футпринт, инвариантна к сдвигу FO), не зависит от камеры/света.
   Проверено скриншотами: сфера = живая серая кривизна, куб = чёрный (норма),
   скошенный+бейк = белые полосы по рёбрам.
   ширина — _EdgeWidth (cutoff 1→0: только пики → вся полоса),
   рваность — _EdgeNoise (ширина заполнения шумом вдоль грани),
   мастер — _EdgeBandMaster.
   На полосу назначаются: _EdgeRust (ржавчина), _EdgeWear (блик-зачистка ядра).
   DebugView=Edge Band показывает именно эту полосу.
1. База стали: BaseColor × B-вариация, Metallic 0.9, Roughness 0.35–0.6
   + слабая вертикальная «волнистость» проката (дешёвый шум).
   ВНИМАНИЕ: металл без окружения/света = чёрный (физика PBR). Для читаемости
   в тёмных сценах нужен key light + env (reflection probe/sky) либо ниже Metallic.
2. Маска стыка M_cavity = max(R-канал, полоса граней × _EdgeToCavity),
   разбитая mid-шумом, чтобы край ржавчины был рваным.
3. Маска верха/потёков M_flow = facing-up (нормаль.y) + потёки вниз:
   шум, растянутый по Y (streak noise), сила — свойство DripStrength.
4. Паттерн ржавчины P = large blotches × mid cells × fine grain,
   всё в object-space, 3 масштаба. Порог — RustAmount + Seed.
5. RustMask = P × M_cavity × (0.35 + 0.65 × M_flow) × RustAmount.
   В зоне RustMask: Albedo → градиент ржавчины (тёмно-коричневый →
   рыжий → светлая кромка подсыхания), Metallic → 0, Roughness → 0.9,
   Normal — дешёвый bump от fine-шума.
6. Эффекты на полосе граней: ядро полосы (edgeBand + рванье fine-шумом)
   поверх ржавчины: **тонкий металлический блик-зачистка** (55% смешивания).
   Ржавчина на гранях доминирует (слой 5 + _EdgeRust), металл лишь
   поблёскивает. Сила — EdgeWear.
```

Порядок наложения: сталь → ржавчина → зачистка кромок → пыль (A-канал,
когда появится общий слой пыли — не в v1).

## 4. Параметры материала (v1)

| Свойство | Тип | Дефолт | Что крутит |
|---|---|---|---|
| `_BaseColor` | Color | серая сталь 0.45 | тон металла |
| `_SteelRoughness` | 0–1 | 0.42 | гладкость чистых зон (в шейдере → smoothness) |
| `_RustColorDark / _RustColorMid / _RustColorLight` | Color | #2a1408 / #8a3b12 / #c47a2e | градиент коррозии |
| `_RustAmount` | 0–1 | 0.5 | главный слайдер старости |
| `_RustScaleLarge / _Mid / _Fine` | Float | 0.6 / 3.0 / 18.0 | плотность шума, штук на мировой метр (v4.3+: нормировано на масштаб объекта) |
| `_CavityTightness` | Float | 1.5 | насколько ржавчина жмётся к самому стыку |
| `_EdgeWear` | 0–1 | 0.6 | сила зачистки кромок |
| `_UpBias` | 0–1 | 0.5 | предпочтение горизонтальных поверхностей |
| `_DripStrength` | 0–1 | 0.5 | потёки вниз от стыков |
| `_BumpStrength` | 0–1 | 0.5 | bump ржавчины; **0 = Far/Low-вариант** (без keyword-вариантов, SRP Batcher не рвётся) |
| `_Seed` | Float | 0 | уникализация объекта (менять на каждый пресет) |
| `_EdgeBandMaster` | 0–2 | 1.0 | мастер канала граней (был `_DerivEdges` до v5) |
| `_EdgeRim` | 0–1.5 | 0.35 | вклад силуэтного рима в полосу |
| `_EdgeWidth` | 0–1 | 0.35 | ширина полосы: cutoff 1→0 (только пики → вся полоса) |
| `_EdgeNoise` | 0–1 | 0.45 | рваность полосы: ширина заполнения шумом вдоль грани |
| `_EdgeToCavity` | 0–1.5 | 1.0 | сколько полоса добавляет в маску стыка/ржавчины (был `_DerivCavity`) |
| `_EdgeRust` | 0–2 | 0.8 | ржавчина, назначенная на полосу граней |
| `_EdgeWear` | 0–1 | 0.6 | металлический блик-зачистка на ядре полосы |
| `_UseVertexColors` | Toggle | **off (0)** | off = чистая процедура по геометрии (дефолт для всех незапечённых мешей); on = читать печёные R/G (только после EdgeMaskBaker!) |
| `_DebugView` | Enum | Off | Rust Mask / Cavity R / Edge G / Pattern — версии для сравнения настройки |

Всё остальное (освещение, тени, GI) — стандартный URP Lit, ничего
кастомного в свет не вводим (SRP Batcher и поведение предсказуемы).

## 5. Требования к геометрии и vertex colors

- Фаски у видимых кромок: дают полосе реальную ширину (данные живут
  на промежуточных вершинах). Рецепт для ProBuilder: bevel + subdivide,
  затем `Bake SteelDemo Objects...` (та же логика, что `Bake Edge Masks`,
  но находит объекты `SteelDemo_*` сам). Жёсткий примитив без фасок
  полосу не удержит — это свойство вершинных данных, не баг шейдера.
- Чистые нормали (пересчёт, без перевёрнутых граней).
- UV не нужны вообще (проекция — object-space). Развёртка — только если
  у меша уже есть лайтмап-UV для GI, шейдеру они безразличны.
- Каналы (договор из `docs/Materials/README.md`):
  R — стыки/вогнутость, G — выпуклые кромки, B — вариация панелей, A — резерв.
- **Основной источник R/G — `EdgeMaskBaker`** (`Tools/ProjectC/Materials/
  Bake Edge Masks (R/G)...`, скрипт `Assets/_Project/Editor/Materials/
  EdgeMaskBaker.cs`): считает двугранные углы из координат (сварка позиций,
  знак выпуклое/вогнутое, порог от 5°), размывает на мировой радиус
  (дефолт 0.15 м — это и есть ширина полосы в метрах), пишет дубликат меша
  в `Assets/_Project/Generated/EdgeBaked/` и подменяет MeshFilter.
  Проверен на кубе: 24→8 точек, 12 рёбер, Gmax=1, Rmax=0.
  Радиус задаётся в мировых метрах (делится на масштаб объекта автоматически).
  ВАЖНО: бейк бесполезен на жёстких примитивах (24-вершинный куб: все вершины
  угловые → G=1 везде, градиенту негде жить). Печёный G работает только на
  мешах с плотностью (фаски/сабдив дают промежуточные вершины). На примитивах
  полагайся на деривативы (тумблер 0).
  После запечки: включить `_UseVertexColors=1` на материалах объекта
  (бейкер пишет подсказку в консоль). Демо-набор (скошенный+поделённый куб,
  запечённый меш, материал `DemoSteel`): `Assets/_Project/Materials/Steel/`,
  меш в `Assets/_Project/Generated/EdgeBaked/`. В BootstrapScene демо-объекты
  НЕ храним (билд-сцена!) — собираются за 5 минут по §9.0.
- **Критично: белый = незапечённый.** Меш без цветов Unity отдаёт шейдеру
  как (1,1,1,1); ProBuilder по дефолту красит всё в белый. Шейдер v4.1+
  детектит чистый белый как «нет данных» и игнорирует его даже при
  включённом тумблере (защита в коде, `useVC`). Но правило остаётся:
  нет запечки → тумблер 0 (все 3 пресета по дефолту 0 — чистая процедура
  из геометрии). Диагностика белого: меню
  `Tools/ProjectC/Materials/Check Vertex Colors on Selected`.

## 6. Floating Origin

Только object-space. Запрещены `AbsoluteWorld`-координаты для шума
(после F8-ребейза паттерн поплывёт). Сид — свойство материала, не функция
мировой позиции. Смена материала/его полей перерегистрации сцен
не требует (контентный пайплайн §3.3: «крутить сериализованные поля —
можно»), проверка — F8/F9: шум стоит на месте.

## 7. Производительность (оценка, замерить при прототипе)

- Near: ~3 выборки процедурного шума (по 2–3 октавы gradient noise) +
  streak-растяжка. Ориентир: дешевле одной трипланарной выборки текстуры
  с анизотропией, дороже плоского Lit. Для героев/кораблей рядом — норма.
- Far: 1 октава, без bump (`_QualityBump` off), те же маски.
- Инструкций бояться не надо раньше замера: главный риск — не ALU,
  а overdraw на больших плоскостях + MSAA. Замер — через URP stats
  после прототипа (делает пользователь или отдельная задача).

## 8. Пакеты: нужен ли что-то докупать/ставить

**Для v1 — нет.** Всё делается ванильным URP 17.5.0 + HLSL + Blender,
который уже в пайплайне. Кандидаты, которых смотрели и отложили:

| Кандидат | Вердикт |
|---|---|
| Polybrush (free, Unity) — красить R/G/B прямо в редакторе | Полезен, но не блокер: bake из Blender + ProBuilder 6.1.2 (уже стоит) закрывают v1. Решение — за тобой, перед установкой спрошу отдельно |
| Screen-space cavity (open-source: URP-ScreenSpaceCavity, cavifree) | Даёт «настоящие» кромки без bake, но: +fullscreen pass в Forward, артефакты на силуэтах, пересечение с нашим EdgeDetection-фичей. Не рекомендую в v1 |
| Asset Store: Rust/Dust Layers, Global Dirt, Cavity Shader | Платные, тащат свои шейдеры/зависимости, часть требует Deferred или UV. Противоречат цели «свои материалы без текстур». Не рекомендую |
| Substance/Painter-bake | Мощно, но вводит текстурный пайплайн, от которого уходим. Только как разовый инструмент художника для hero-персонажей, не для 95% |

Если решишь ставить Polybrush — скажи, подготовлю план установки
(это `ProjectSettings`/`Packages` — по HARD RULES только с твоего одобрения).

## 9. Настройка

### 9.0. Быстрый тест (5 минут, без Play Mode) — только на скошенном меше

Жёсткий примитив полосу НЕ покажет (все вершины угловые + `fwidth` мёртв
здесь — см. §2). Правильный тест — скошенный куб:

1. ProBuilder-куб → bevel всех рёбер → subdivide → `Tools/ProjectC/
   Materials/Bake Edge Masks (R/G)...` → в консоли `OK ... Gmax>0`.
   (Готовый набор: материал `DemoSteel`, запечённый меш лежит в
   `Assets/_Project/Generated/EdgeBaked/` — объект собирается за 5 минут,
   в билд-сценах демо-объекты НЕ хранить.)
2. Материал с `_UseVertexColors` — ВКЛ, `_DebugView` → **Edge Band**:
   белые рваные полосы по рёбрам на чёрном = канал работает.
3. `_DebugView` → Off + свет СПЕРЕДИ объекта (directional с ротацией в сторону
   камеры, иначе контровый свет даст чёрный металл): ржавые полосы +
   металлический блик. Весь объект чёрный при белых полосах = света нет
   с нужной стороны (metallic 0.9, физика PBR) — проверено: ротация света
   на 180° превращала освещённый куб в чёрный и обратно.
