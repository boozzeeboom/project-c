## 2. Действующее правило (v9 + v10 + именование)

1. **Полотно** = объект с `_DOOR` в имени, не арка/лампа/склад, и габарит:
   высота **1.6–3.2 м**, ширина (max горизонтали) **0.35–4.5 м**, толщина **≤0.30 м**,
   толщина/ширина **≤0.35** (порог 0.15 был ошибочен — в RING полотна 0.15/0.80 = 0.19).
2. **Группировка**: полотна кластеризуются по близости (зазор ≤0.10 м) внутри дома;
   **дом = всё до `_DOOR`** (`RES_RG_E_21_DOOR_WC` → `RES_RG_E_21`).
3. **Части** (фурнитура/панели/косяки по токенам `KICK/KNOB/PANEL/FRAME/JAMB/LINTEL/HNG/ROS/
   POST/LOCK/LVR/BOLT/HINGE/KEY/...`) добираются к ближайшей двери своего дома (зазор ≤0.15 м,
   площадь ≤1.0 м²), одна часть — только к одной двери (`assigned`-набор).
4. **Склады** (`*_DRS_*`, `*_DOOR_HARD`, `*_DOOR_PANELS`) режутся на острова и приклеиваются к
   ближайшей двери своего дома (порог 8 м).
5. **Улетевшие объекты** (центр вне горизонтального робастного bbox чанка +15 м) → узел
   `OUTLIERS` (не склеиваются, в Unity выключать).
6. **Имя двери** = `<исходное>_<W>x<H>_X`, где W = max горизонтального размера.
7. **Масштаб k=1.07** — только на меш-объекты; пивот двери = низ по центру.
