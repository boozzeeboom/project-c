# Треки: журнал полётов (v1)

**Дата:** 2026-09-17
**Статус:** ✅ Реализовано (сессионно, без персиста)
**Код:**
- `Assets/_Project/Scripts/World/ChartTrackRecorder.cs` (`ProjectC.World`) — запись
- `Assets/_Project/Scripts/UI/Chart/ChartWindow.cs` — отрисовка (слой «Треки»)
- `GlobalMotionControlledRebaseSlice` — хук `ShiftChartTracks` (3 пути)

## 1. Формат записи (давность + источник с первого дня)

`ChartTrackPoint { worldPos, utcSeconds (Unix), source }`.
Источник: `Self` (пишет сейчас) / `Purchased` / `Crew` (резерв под будущее).
Давность считается в отрисовке: свежее 10 мин — ярко (α 0.85),
к 3 часам выцветает до α 0.15.

## 2. Запись

- Точка, если ушли ≥25 м от прошлой И прошло ≥5 с (настраивается в Inspector).
- Пишется всегда (пешком и в корабле), не только с открытой картой:
  `ChartWindow.Awake → EnsureExists()` создаёт DontDestroyOnLoad-рекордер
  на старте сессии. В редакторе (не Play) не создаётся.
- Кольцо 2000 точек, старые вытесняются. Прореживание = естественная чистка.

## 3. Floating Origin (🟡-кейс, закрыт)

Точки — мировые Vector3 между кадрами → `ApplyRebaseTranslation` сдвигает
журнал + якорь `_lastRecorded`. Подключено в слайсе как шторма/коридоры:
success-путь, rollback-путь (−T), клиентский broadcast-handler. Маркер:
`ChartTracksShifted (points=N)`.

## 4. Отрисовка

Ломаная своих точек (чужие источники пропускаются — их слои позже),
разрыв сегмента за экраном, ширина 2. Легенда оживает: `— Треки (N)`,
пусто — `— Треки (лети — запишу)`.

## 5. Не сделано (следующие шаги)

- Персист между сессиями (с кумулятивом сдвига по паттерну PERSIST01).
- Ручные метки (следующий слой по плану).
- Купленные/экипажные треки другим «почерком».
