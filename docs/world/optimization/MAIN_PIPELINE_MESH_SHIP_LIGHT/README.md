## 1. Пять зафиксированных решений (2026-11-01, не пересматривать без нужды)

1. **Дома строим как раньше — блочной поставкой.** Дом = юнит внутри блока `(блок × материал)`, префабов домов
   не вводим. Это не «компромисс», а самая дешёвая гранулярность: дробление по дому (B2) даёт 330 батчей против 160
   и **рост DC**; текущие **3.4 DC/дом** — уже результат правильной склейки. Новые поселения — тем же способом,
   блоками по 25–45 домов.
2. **HLOD бейкаем по факту наполнения.** Не после каждого ассета, а когда готов ряд/квартал (например, ряд из 10 ферм) —
   тогда `Stage 7 HLOD → Bake All Blocks + L2` + `Rebake Determinism Check`. До этого новый контент живёт в L0 (<3 км)
   — это нормально и не требует отдельного решения.
3. **Всё в `WorldScene_0_0`.** Архитектурный вопрос «раскидать мир по сетке 6×4 сцен» сейчас **не поднимаем**:
   `WorldScene_0_0` отвечает за всё. Следим только за размером файла (сейчас 60 МБ; при приближении к ~100 МБ — вернуться).
4. **Канон масштаба — `k = 1.06`.** Примум помещён с 1.06; 1.07 в старых README — опечатка, не использовать.
5. **Фермы — без отдельных слоёв по группам.** Всё под `Primum_farms` (+ `Primum_farms_DOORS`, слой 10 у дверей).
   Слой визуала и ламп — **8 `PRIMUM`**, как у города и порта (проверено на 0-3, 0-4 и `PRIMUM_PORT`);
   отдельного слоя на каждую ферму не вводим — см. [`SETTLEMENTS.md`](SETTLEMENTS.md) §7.7–7.8.
   FBX остаются вне git (как сейчас); **префабы можно вести в git** — если станут тяжёлыми, решим позже
   (для этого понадобится точечное исключение из `.gitignore` с одобрения).
