# 2026-11-08 v2.1 — DeepSeek за Нулей на исправленном движке

## Что это

Первый **чистый** прогон v2 после P0/P1-фиксов (`AUDIT_V13D.md`). Тот же промпт v2 и те же условия, что в v2/v2-ext6, но движок v1.3d: без ухода за доску, без порчи при оттеснении, без оттеснения нулями, с корректными щитами и приоритетом king/hold.

- 10+1 C1, **Стрелка + Основной**, лимит 60.
- DeepSeek 4.1 Flash — только Нули; Плюсы/Минусы — ИИ v1.3c.
- 6 игр, номера **721–726**.
- Промпт — `prompt.txt` (копия v2, без изменений; action list изменился только удалением нелегальных действий).
- Арена: integrity-guard после каждого действия + логирование `raw`/`plan`.

## Ключевое

- **725 — чистая победа удержанием.** План модели читается: занял «Ц» с жёлтых ворот, удерживал, при угрозе переставил Скитальца на (2,0)/(1,0), вернул Свободного на центр и довёл Hold до 3. Это **первое чистое доказательство на исправленном движке** (после чистой 711 на старом движке), что доктрина v2 работает, когда модель действительно доходит до центра.
- **В остальных 5 играх Нули не удержали «Ц» ни одного тика** (`zeroHoldMax=0`): 721/723/724/726 — военные удержали раньше; 722 — Линейный погиб на 8-м ходу, у Нулей было 2 действия.
- **Осцилляции снизились:** 3 возврата на 44 хода (6.8 %) против 20/55 (36 %) в v2-ext6, но 724/726 всё ещё дают 1–2 возврата и 8–11 повторов одной фигуры.
- **Поддержка по-прежнему редка:** 3 на 47 действий (6.4 %).
- **Движок чист:** 0 off-board, 0 duplicate/unlinked, 0 stale supports; единственное `displace` — легальное оттеснение военным ИИ в 725, доска не испорчена.
