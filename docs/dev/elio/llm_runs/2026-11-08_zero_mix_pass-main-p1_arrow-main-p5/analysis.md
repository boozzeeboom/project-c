## 4. Как играл DeepSeek

### Победы

- **731 (16 ходов):** быстрый захват «Ц» Свободным `Z-F28`, поддержка, 4 center ticks, Hold 3.
- **732 (28 ходов):** 12 ходов, 6 к воротам, 8 center ticks; удержание, несмотря на 3 осцилляции.
- **736 (29 ходов, 15 фигур):** самый содержательный план. Модель последовательно использовала **трёх скитальцев** `Z-S45 → Z-S44 → Z-S43` для борьбы за центр, затем поддержала парламент и перекрыла вход Свободным. 7 center ticks, Hold 3.
- **740 (18 ходов, 15 фигур):** быстрый Hold 3; 5 действий, 3 к воротам, 3 center ticks.

### Поражения

- **733 (31 ход, Pass):** Нули дошли до Hold 2, но Минусы удержали раньше.
- **734 (8 ходов, Pass):** Плюсы убили Линейного Минусов на 8-м ходу; у Нулей было 3 действия. Это не ошибка доктрины, а темп Main.
- **735 (49 ходов, Pass):** долгая игра, 17 действий, 0 center ticks; Минусы удержали.
- **737 (27 ходов, 15):** Минусы убили Линейного; у Нулей 0 hold, 2 center ticks.
- **738 (36 ходов, 15):** Нули дошли до Hold 2, но Плюсы удержали раньше; 2 легальных оттеснения ИИ.
- **739 (18 ходов, 15):** Плюсы быстро удержали; у Нулей 0 center ticks.

**Закономерность:** все 4 победы — `zeroHoldMax=3`; в поражениях 733/738 Нули были в одном тике от победы. Главный дефицит — успеть удержать 3 тика до военного Hold/king.

## 5. Ошибки кода/аудита, найденные по результатам

### 5.1. Audit-скрипт жёстко инициализировал 10+1 / arrow

`elio_run_audit.js` делал `E.init({turn:'arrow', death:'main', pawns:1})` для любого лога. Для 15-фигурной игры 736 это дало `replayOk=false`, `illegal=1` — **ошибка аудита, не игры**. Исправлено: init берёт `m.mode.turn`, `m.mode.death`, `m.pawns`, `firstMovePawn=(pawns>=5)`; лимит — из `m.limit` или по причине/пешкам. После фикса 736: `replayOk=true`, 0 illegal, 14 действий, 7 center ticks.

### 5.2. Pass-логирование

Арена теперь:
- для ИИ передаёт `mv.passTo` и логирует его;
- для LLM выбирает случайный `passTo`, передаёт его в `applyMove/Support/Skip` и логирует.
Replay pass-игр использует `entry.passTo`; все pass-логи 731–735 — `replayOk=true`.

### 5.3. Promt/arena accuracy

Системный промпт для pass-режима теперь говорит: «движок случайно передаёт ход… (ты не выбираешь получателя)». Раньше он говорил «отдаёшь ход», хотя LLM этого не делает. Это устранено в арене mix-прогона.

### 5.4. Доки

- 10+1/15 — тест-варианты; 5 игр — пилот.
- Pass — random baseline; LLM не выбирает получателя.
- 10+1 limit 90, 15 limit 120; LLM-арена ранее использовала 60 — не смешивать.

## 6. Вывод

- **Это лучший пилот DeepSeek за Нулей:** 4/10, по 2/5 в каждом сетапе, ровно на уровне AI-базы Нулей (40.5 % / 40.0 %).
- **Оба сетапа — zero-favored** (Нули ~40 %, Плюсы/Минусы делят остальное), а не «ровный баланс». Если нужен ровный тест — 10-фигурный Pass+Long 34/33/32.
- **15-фигурный сетап полезен для доктрины:** 5 скитальцев дают модели больше тел для центра; 736 — пример осмысленной многоходовой игры.

- **5 игр на сетап — мало:** ±~20 п.п. Для подтверждения нужно 20–50 игр на сетап.
