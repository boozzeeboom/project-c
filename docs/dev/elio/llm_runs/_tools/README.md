# `_tools` — проверки движка и аудит LLM-логов

> Запускать из любой папки, Node.js. Пути к движку относительные (`../../elio_engine.js`).

## `elio_engine_bugs.js`

Точечные unit-проверки правил/движка. Каждый пункт — `{ name, expected, actual, ok, detail }`; `"ok": false` — найденный баг.

Покрывает:
- уход одношаговых фигур за доску;
- порчу доски при `applyMove`-оттеснении;
- оттеснение нулями;
- `applyDisplace` без соседства;
- залипшие щиты при дистанции >1;
- приоритет hold над king;
- оттеснение по осям q=0/r=0;
- replay оттеснения в recorder;
- ауру Инженера на Нулях;
- лимиты 90/120;
- запрет поддержки Скитальцем;
- вход на «Ц» только с ворот;
- уязвимость нуля на «Ц».

```bash
node elio_engine_bugs.js
```

## `elio_run_audit.js`

Replay сырых логов арены и аудит:
- легальность каждого действия;
- совпадение `after`/`winner`/`reason` с replay;
- целостность доски (все живые на валидных клетках, нет дублей/несвязанных);
- залипшие щиты;
- осцилляции (возврат на прошлую клетку, 2-цикл);
- повтор одной фигуры;
- пропущенные защиты Линейного (щит был доступен, но не выбран);
- возможности входа на «Ц»;
- support-цели.

```bash
node elio_run_audit.js path/to/match711.json path/to/match712.json ...
# или массив игр:
node elio_run_audit.js path/to/elio_zero_test.json
```

Пишет `elio_run_audit.json` в `C:/Users/leon7/AppData/Local/Temp/opencode/` (путь `OUT` в коде).

## `elio_bug_frequency.js`

Headless-выборка 40+40 игр ИИ v1.3c: считает `displace`, ходы за доску, игры с порчей доски, исходы. Нужна, чтобы оценить, насколько 400-партийные цифры могли быть искажены.

```bash
node elio_bug_frequency.js
```

## Важно

- Это **диагностика**, а не часть веб-прототипа; в UI/движок не импортируется.
- После P0-фиксов `elio_engine_bugs.js` должен быть полностью зелёным; `elio_bug_frequency.js` — 0 displace/off-board/integrity.
