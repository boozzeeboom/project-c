# 2026-11-08 — DeepSeek за Нулей против двух ИИ

## Гипотеза

Если дать DeepSeek 4.1 Flash **отдельную доктрину Нулей** — с признанием слабости, приоритетом «не допустить смерти Линейных», тактиками щитов/блоков/стравливания и планированием на 2–3 хода, — то он сможет играть за Нулей лучше, чем в общем промпте.

## Условия

- **10+1 C1**: 11 фигур на флот, одна пешка в `C1`, без обязательного первого хода пешкой.
- **Стрелка + Основной**: первый ход случайный, гибель любого Линейного = немедленная победа убийцы.
- **DeepSeek 4.1 Flash** играет только за **Нулей**; за Плюсов и Минусов — встроенный ИИ v1.3c.
- 3 игры, лимит 60, low reasoning, топ-16 действий для Нулей.
- Модель получает общий system prompt + `ZERO_DOCTRINE` (см. `prompt.txt`).

## Итог

Заполняется после прогона — см. `analysis.md` и `summary.json`.

## Файлы

- `PROMPT_DESIGN.md` — почему промпт такой.

- `matches/` — 3 сырых лога.
