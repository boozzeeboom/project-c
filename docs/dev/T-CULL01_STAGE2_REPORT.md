## 3. Бюджет теней (Stage 2b)

`DoorVisibilityBudget`, тени дверей:

- группы = **2 598** (корень двери по `DoorController`; без этого деления группами становились бы
  меши с собственными коллайдерами — 5 488 групп);
- гистерезис: включение при `< 50 м`, выключение при `> 60 м` (запрошенный диапазон 40–80 м);
- обновление **0.33 с (≈3 Гц)**, не каждый кадр; меняется только `Renderer.shadowCastingMode`,
  исходный режим каждого рендерера запоминается и восстанавливается при возврате;
- мультикамерный union: тени включены, пока дверь ближе хотя бы к одной геймплейной камере;
- `SetActive`, `Renderer.enabled`, `DoorController` и коллайдеры не трогаются;
- FO-safe: мировые позиции не кэшируются, дистанции считаются от живых трансформов каждый тик.

`ShadowBudget`, дальняя геометрия:

- корни по имени (`Primum_farms`), группы = прямые дети (фермы/чанки), **145 рендереров**,
  слой дверей (10) исключён, чтобы не спорить с `DoorVisibilityBudget`;
- та же дистанционная логика 50/60 м; если игрок подлетит к ферме, тени вернутся;
- оговорка: `URP shadowDistance = 1000 м`, фермы стоят в 5.7–6.0 км от P1, то есть в shadow-pass
  они и так не попадают. Выигрыш от этого блока ожидается **≈0**; реализован по §2c брифа.

Проверено в edit mode на живых инстансах (200 сэмплов, шаг по всем 2 630 `DoorController`):

| Проверка | Результат |
|---|---|
| `Physics.GetIgnoreLayerCollision(10, *)` | **0 игнорируемых пар** — матрица слоя 10 по умолчанию сталкивается со всеми |
| `OverlapSphere(bounds.center, 0.05, ~0)` | **200/200** — коллайдеры дверей живы и участвуют в физике |
| `OverlapSphere(..., 1 << 10)` | **199/200** (+1 сэмпл — дверь корабля, оставшаяся на своём слое) |
| `OverlapSphere(..., 1 << 8)` | **0/200** — на `PRIMUM` дверей больше нет (ожидаемо) |
| коллайдеры включены / триггеры | 200/200 включены, 199 триггерные (как в префабах) |
| `Raycast` сверху вниз, маска `1 << 10` | 188/200 попали в дверь; 12 — луч упёрся в перекрытие/соседнюю геометрию выше двери |

Аудит масок: в `Assets\_Project\Prefabs` все `m_Bits` — `4294967295` (все слои), ни одной маски,
ограниченной `PRIMUM` (`256`). То есть перенос дверей на слой 10 не выкидывает их ни из
`SpringArmCamera.collisionMask`, ни из `_platformMask`, ни из `GazeAutofocus`/`FarFocus`, ни из
`~0`-запросов `CombatServer`/`TargetingService`/`SkillInputService`. `Camera.layerCullDistances`
на физику не влияет.

Целостность префабов после `SaveAsPrefabAsset`: во всех 12 префабах на месте `DoorController`,
коллайдеры и рендереры (8/3/1/1/3/3/3/2/5/2/2/2 — совпало с dry-run), живые ссылки створок
сохранены (`DOUBLE`/`PALACE` — 4 живых референса, `GATE` — 1).
