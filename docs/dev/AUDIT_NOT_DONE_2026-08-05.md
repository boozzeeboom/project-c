## 2. Изменения scope (решения 2026-08-05)

- **Лобби/комнаты (`RoomManager`)** — отменено. Вместо: подключение к хосту по IP через сервисы типа Steam, запуск сервера-хоста.
- **P2P-торговля** — целевая версия **0.8.0** (этап тестирования, там доделываем всё накопившееся).
- **World Streaming + Floating Origin + PositionCorrection** — целевая версия **0.7.0**.
- **SOL/Veil геймплей** — целевая версия **выше 0.2.0**.
- **Наполнение мира** (внешняя торговля, фракц. производства, чёрный рынок, анклавы; crafting-контент; лимиты веса/объёма; автопилот стыковки; компас/карта; Camera Impulse; clothing overrides UI) — **выше 0.1.0**.
- **Локализация** — **0.0.90**.
