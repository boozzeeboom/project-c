## 3. Вывод

- В 10+1 C1 **один DeepSeek против ИИ играет 1–9**: встроенный ИИ значительно сильнее.
- **Два DeepSeek против одного ИИ — 2–1** (3 игры): две LLM-фракции уже могут навязать борьбу, но обе победы — за военную фракцию, одна по лимиту 30. Это эффект **количества LLM-фракций**, а не силы одной модели.
- DeepSeek по-прежнему играет поверхностно: 0 убийств Линейного, 0–1 угроз, 60–64 % повторных ходов одной фигурой, 9–21 % осцилляций. У ИИ capture/center эффективность выше.
- 10+1 C1 не делает LLM конкурентоспособнее: правило/пешка не компенсируют слабое пространственное планирование.
- Ограничение: 10 игр 1×DeepSeek и 3 игры 2×DeepSeek — это **пилот**, не полноценный турнир. Для выводов по режимам нужно больше игр.

## 4. DeepSeek за Нулей: Zero-доктрина (v1 → v2.1)

Отдельный эксперимент: DeepSeek играет **только за Нулей** против двух ИИ, 10+1 C1, Стрелка + Основной. Промпт получил доктрину: «Нули заведомо слабее; не дай умереть Линейным; займи Ц; щитуй, блокируй, стравливай». Логи и разборы — `llm_runs/2026-11-08_zero_10plus1_arrow_main*`.

- **v1 был сломан harness’ом:** для Нулей список действий сортировался «поддержки первыми», и в топ-16 не попало ни одного хода. DeepSeek делал только поддержки — 0 ходов.
- **v2 pilot:** action list исправлен — до 10 ходов (приоритет ворота/«Ц») + до 6 поддержек. Появилась чистая победа удержанием (711, 20 ходов).
- **v2-ext6:** 6 дополнительных игр дали **1–1–4**, но **3 игры contaminated**:

  - 716 — Линейный Плюсов ушёл за доску (`legalMoves` не проверяет `isValidCell` для одношаговых фигур).
  Чистые 714/718/719 — **0–0–3**.
- **Чистый итог v2: 1 победа, 0 ничьих, 4 поражения.** Единственная чистая победа — 711. 717-победа **не является** доказательством доктрины.
- **v2.1 — первый чистый прогон на v1.3d:** **1–0–5, 0 contaminated, 0 illegal, 0 integrity, 0 stale supports.** 725 — чистая победа удержанием (`zeroHoldMax=3`); в остальных 5 играх `zeroHoldMax=0`. Осцилляции 3/44 (6.8 %) против 20/55 (36 %) в ext6; поддержки 3/47.
- **Headless 400 (v1.3d):** Pass+Main p1 (fixed passTo) — **27.25 / 31 / 40.5**; Arrow+Main p5 — **25.25 / 34.75 / 40**. Оба zero-favored ~40 %; 100-игровые 29/33/36 и 32/31/37 были шумом/багом. См. `balance/2026-11-08_headless400_pass-main-p1_arrow-main-p5/`.
- **Zero mix (10 игр):** 2/5 Pass+Main 10+1 + 2/5 Arrow+Main 15 = **4/10 (40 %)**; ровно AI-база Нулей 40.5/40.0 %. 0 contaminated; passTo fix. 5 игр на сетап — пилот; 736 — 5 скитальцев, осмысленный план; 731/732 — hold 16/28. См. `llm_runs/2026-11-08_zero_mix_pass-main-p1_arrow-main-p5/`.
- **Beam Free (10 игр, Arrow+Main 15, v2, без v3): 1–0–9 (10 %).** vs AI 40 % / DeepSeek 40 %; **69 % осцилляций (45/65 ходов)**, 6 center ticks за 10 игр; в 8 играх из 10 — 0 center ticks. 754 — 0 ходов Нулей (удача стрелки), 758 — 1 ход; формат 0 fallback. Промпт/движок идентичны DeepSeek → причина в исполнении: Beam не доходит до центра и болтает фигуру. Единственная победа 756 — 0 осцилляций, 3 center ticks. См. `llm_runs/2026-11-09_beam_zero_arrow-main-p5_10/`.
- Остались проблемы: 30/47 повторов одной фигуры; 724/726 всё ещё дают возвраты; 5 из 6 игр — 0 center ticks.
- **Приоритет «защити Линейного» часто невыполним в 10+1 C1:** в 715 угроза возникла после последнего хода Нулей, в 718 ни один нуль не был соседним с Линейным под угрозой (`noDefenseAvailable=2`). Нужна развилка «щит, если дотягиваешься; иначе — «Ц»/блокировки».
- **P0-фиксы движка сделаны** (`AUDIT_V13D.md`), integrity-guard в арене работает; 400-партийный баланс ещё не перепрогнан.
- Вывод: **исправление action list важно, но одного этого мало.** v2.1 даёт 1–0–5; 725 доказывает, что доктрина может работать, но нужен v3: жёсткий анти-осцилляционный фильтр, приоритет «Ц» при недостижимом Линейном, победа по лимиту, типы движения Нулей.



*Пилот, не полноценный турнир: 10 игр матрицы, 9 игр v2 и 6 игр v2.1; для выводов нужна большая выборка.*
