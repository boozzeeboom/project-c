# T-SHIP-DOC06 — перепроверка: Engine vs Broken (топливный кросс-эффект)

> Тикет: `T-SHIP-DOC06`. Дата: 2026-09-18. Статус: **ПОДТВЕРЖДЕНО**.
> Scope: только перепроверка + кросс-ссылки в доках. Кода/баланса нет.

## Что проверяли

Утверждение ревью (§7 несостыковок): `ENGINE_POWER_STATE.md` (`OFF=падение`,
`fuel==0=авто-OFF`, IDLE `0.05/s`) vs `damage_subsystem/00_DESIGN.md §4`
(`Broken: двигатель НЕ выключается, скорости ×0.1, расход как обычно`) —
следствие (сломанный жрёт ~x10 топлива на ту же дистанцию → потом падает
по engine-правилу) нигде не зафиксировано, кросс-ссылок нет.

## Факт (сверено чтением доков)

- `ENGINE_POWER_STATE.md §2.5` (строки 50–55): `fuel==0` → авто-OFF; расход всегда
  (с вводом `ConsumeFuelPerSecond`, IDLE `0.05/s`); оставленный ON → потратит → OFF → падение.
- `damage_subsystem/00_DESIGN.md §1` (строки 18–22) + `§4` (строки 102–106) + `§4.1`
  (строки 118–119): `BROKEN`: «Двигатель работает», «Скорости ×0.1», «Корабль не уничтожен»;
  «Двигатель **не выключается** при поломке — корабль может ковылять на 10% скоростей».
- Ни в одном из файлов нет упоминания второго: ENGINE не знает про Broken,
  DAMAGE не знает про fuel-авто-OFF. Кросс-эффект (x10 расход/дистанция → авто-OFF → падение)
  выводится только комбинацией, в доках отсутствует.
- Кодовый баланс (менять расход/множитель) — НЕ этот тикет.

## Решение

Статус ПОДТВЕРЖДЕНО. Фикс docs-only: кросс-баннеры в оба дока
(ENGINE §2.5 ↔ DAMAGE §4.1) с формулировкой следствия. Баланс не трогаем.

## Проверка

- Читать оба дока: баннеры-ссылки на месте.
- Compile: не требуется (docs only).
