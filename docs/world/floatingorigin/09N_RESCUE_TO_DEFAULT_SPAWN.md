# T-FO09N: Esc-«Спасение» — строго на дефолтную точку (revert T-FO09C)

## Решение
- `ForceDefaultRespawnServerRpc` → `PerformDefaultRespawn` идёт СТРОГО на
  дефолтную точку RespawnManager (город). Ship-цепочка убрана.
- Возврат на корабль — только два пути:
  1. автореспавн при падении (`PerformRespawn` → `TryResolveShipRescuePosition`:
     текущий → последний → ближайший owned);
  2. посадка при перезаходе (`NetworkPlayer.WaitForShipAndBoard`, T-FO09H).

## Почему revert 09C
09C направлял ручное «Спасение» через ship-цепочку, чтобы не возвращать
в пустоту под удалённым граундом (06K). Причина устранена иначе:
fallback-точки сдвигаются с миром (09G), точка спавна перенесена sibling
на землю. А семантика кнопки — «застрял, верни на спавн даже с кораблём» —
была сломана. Возвращена исходная семантика T-PLAYER-PERSIST.

## Границы
- `TryResolveShipRescuePosition` оставлен как общий helper автореспавна.
- `WaitForShipAndBoard` не тронут.
- DeathY/кулдауны/флаги не менялись.

## Проверка
- `refresh_unity` (force + compile) → PASS; `read_console` (errors) → 0.
- Ручной тест (пользователь): Esc-«Спасение» с корабля → дефолтная точка
  в городе; падение с корабля → возврат на корабль; выход на корабле →
  заход → посадка на корабль.
