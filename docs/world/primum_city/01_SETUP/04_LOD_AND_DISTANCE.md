# 04. Дальность: L0 / L1 / L2 (фаза 4)

Дата: 2026-10-17. Цель фазы: город читается как ориентир с 12–80 км за 1–2 draw calls, вблизи — полной
геометрией, ночью — огнями. Это ровно та конструкция, которая уже запроектирована в
`chunk_system/03_DISTANT_CITIES_TERRAIN.md` §3, но до сих пор не сделана.

---

## 1. Три уровня

| Уровень | Дистанция | Что показываем | Техника | Кто владеет |
|---|---|---|---|---|
| **L0** | 0–3 км | полные блоки: меши по материалам + коллайдеры + интерьеры | обычные рендереры в сцене | `PRIMUM` под `WorldRoot_0_0` |
| **L1** | 3–12 км | **HLOD кварталов**: 1 меш на блок, окна эмиссией, мелочь скрыта | запечённый в редакторе меш + `LODGroup` | блок `PRIMUM_BLK_*` |
| **L2** | 12–80 км | **1 билборд-квад на город** (силуэт с альфой) + квад ночных огней | предрендеренный спрайт, camera-facing | `PRIMUM_IMPOSTOR` под корнем сцены |

Калибровка дистанций — по пресетам `ViewDistanceConfig` (Near 30K / Medium 60K / Far 120K) и `fogScale`;
пороги `DistantFocus` (800/4000) **не менять**.

## 2. L0 — полные блоки

* Блоки и их объединение — фаза 2–3 (`02_BLOCKS_AND_GEOMETRY.md`, `03_UNITY_ASSEMBLY.md`).
* Коллайдеры — только там, где нужно ходить/садиться (площадь, улицы, интерьеры), по блоку.
* Интерьеры: либо в меше блока (вариант A), либо отдельным набором по требованию (вариант B) — см. `02` §4.

## 3. L1 — HLOD кварталов

1. Для каждого блока (или группы 3–5 блоков) собрать упрощённый меш: без интерьеров, без мелочи
   (< 0.25 м), окна — плоскими квадами с эмиссивным материалом, крыши/парапеты сохранить.
2. Bake — **в редакторе**, не в рантайме. Ассеты кладём рядом со слоями террейна (пути вне `*Textures*` —
   иначе не попадут в git, см. `terrain/README.md:54`).
3. Переключение — `LODGroup` на блоке: LOD0 = полный блок, LOD1 = HLOD, cull = L2-импостор.
4. Мелочь (декор, трубы, лампы) скрывается по логике `DetailDistanceCuller` (`renderer.enabled=false`,
   без выгрузки — принцип «дешевле, но не off»).

## 4. L2 — импостор города

1. **Предрендер силуэта:** камера-ортогональ с 4–8 направлений → `RenderTexture` → спрайт с альфой
   (как запроектировано для горных пиков: `Landscape_TechnicalDesign.md:404-407`).
2. **Ночной квад:** отдельный спрайт огней, emissive, без теней; читается сквозь туман лучше геометрии.
3. **Поведение:** camera-facing, позиция пересчитывается от камеры каждый кадр; хранить только **скаляры**
   (текущий LOD, дистанция) — тогда FO-класс **🟢** (`chunk_system/03_DISTANT_CITIES_TERRAIN.md` §3).
4. **Требование геймдизайна:** у города уникальный силуэт (купол админкорпуса, шпили, трубы) — силуэт обязан
   узнаваться на 20–80 км; если силуэт «плывёт» — переделываем ракурс/подсветку bake, а не геометрию.
5. **Запрещено:** генерировать импостор в рантайме из сида; выключать дальний террейн (L2 никогда не off).

## 5. Материалы и батчинг

* Материалов у города немного (16–38 на чанк) — комбинированные меши дают 1 draw call на материал-подмеш.
* GPU-инстансинг и `StaticBatchingUtility` — **осторожно**: мир двигается под Floating Origin, поэтому
  объекты сцены **не помечаем static** (в проекте так же сделаны руины: `isStatic = false`,
  `optimization/README.md:16`). Батчинг — динамический/инстансный, не запечённый в статику.

## 6. Критерии приёмки фазы 4

- [ ] с 0.5 км виден полный город (блоки, интерьеры, коллайдеры)
- [ ] с 5–10 км город не «рассыпается»: включены HLOD-меши, мелочи скрыты
- [ ] с 20–80 км город = 1–2 draw calls (силуэт + огни), узнаваем по силуэту
- [ ] ночь: огни видны поверх тумана, силуэт читается
- [ ] F8/F9: импостор и HLOD едут с миром (FO-класс 🟢 подтверждён), 0 errors
- [ ] три пресета ViewDistance (Near/Medium/Far) не конфликтуют с LOD-дистанциями
