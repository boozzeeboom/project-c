# Эльо — поле (прототип)

## Финальная версия

- `prototype_v50.html` — **ФИНАЛЬНАЯ**: 3 поля по 19 гексов (D=3) + 6 спорных гексов + 1 центральный гекс «Ц». 4 жёлтых гекса = центр захвата (3 внутренних лепестка + 1 центральный «Ц»). Все спорные примыкают к 2 полям (мосты), кольцо неразрывное (64/64). Треугольник основания удалён. Нумерация: кольцевая (A1..A12, B1..B6, C1) + спорные по соседям (PZ-1/PZ-2, MZ-1/MZ-2, PM-1/PM-2). Подписи полей: «ПЛЮСЫ» вверху, «МИНУСЫ»/«НУЛИ» ниже полей. Поле опущено (ORIGIN.y=440, viewBox 850×800). 0 наложений, 0 ошибок.

## Играбельный прототип (v51)

- `elio_game_v51.html` — играбельная версия: движок (`elio_engine.js` v1.3), доска (`elio_board.js`), ИИ (`elio_ai.js` v1.3c), запись/воспроизведение (`elio_recorder.js`).
- v1.3: **6 типов** × 3 фракции (у военных добавлены **Линкор**-«ладья» и **Бомбардир**-«дальний конь»), 10 фигур на сторону, расстановка «Полумесяц» (7 на dist 2 + 3 на dist 1); лестница защиты 0/1/2; заявка/оттеснение; поддержка 1→1 (нуль может щитить нуль); счёт «Ц» по **фракции** + правило полного круга; два режима хода в UI (Цикл / Стрелка), третий режим «Передача хода» — в правилах и headless-тестах; два типа игры (Основной «убил=победил» / Длинный «выбывание»); лимит 90.
- Поддержка: ходы по клику, подсветка легальных ходов и целей поддержки (жёлтым), маркеры короля и щитов, селекторы режима, лог в шахматном стиле (move / skip / support / displace), экспорт JSON и replay с этими же записями.
