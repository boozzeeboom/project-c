## Исследование и исправления анализа v1
Дата: 2026-10-26. Локальный CLI подтвердил Blender 5.2.3 LTS.
Веб-поиск в текущем интерфейсе не вернул пригодный для цитирования текст. Первичные страницы Blender Manual и CGAL прочитаны напрямую HTTP-запросами; утверждения о поведении локальной версии дополнительно проверяются RNA и тестами.

Первоисточники:
- Blender Manual, Editing UVs: https://docs.blender.org/manual/en/latest/modeling/meshes/uv/editing.html — packing FRACTION измеряется долей UV-квадрата; заполнение площади и качество параметризации — разные цели.
- Blender Manual, Render Baking: https://docs.blender.org/manual/en/latest/render/cycles/baking.html — Emit, tangent-space Normal, Extend/Adjacent Faces, active image target.
- CGAL Surface Mesh Parameterization: https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html — требования ориентируемой многообразной поверхности, разрезы, различия гарантий биективности. Диск — не универсальное ограничение всех методов параметризации. Одного χ=1 недостаточно для произвольной non-manifold сетки.
- glTF exporter manual: https://docs.blender.org/manual/en/latest/addons/import_export/scene_gltf2.html — первая HTTP-попытка завершилась сетевой ошибкой; свойства экспорта не считаются установленными по этому запросу.

Ошибки предыдущего ответа:
1. Smooth меняет прокси, а не исходный силуэт. Риск — выбор плохих швов, не уничтожение геометрии.
2. 600 итераций, 20–60 итераций и углы 30–45° не являются универсальными пресетами. Нужны масштабно-инвариантные признаки и измерение результата.
3. Число арматур/габариты не подтверждают сохранность весов, костей, анимации и pivot.
4. Join обычно приводит результат к одному мешу: QA v1 способен пройти после потери разделения объектов.
5. Нельзя заключать по именам папок, что все предметы имеют плохой UV, и нельзя гарантировать улучшение ручного UV.
6. Normal map нельзя обрабатывать как обычное RGB при смене UV/tangent basis.
7. Сумма площадей UV не является площадью объединения при overlap. Границы островов и bleed требуют отдельного контроля.

## Дизайн
- Нативный .blend — сохранный результат, содержащий объекты, родительство, трансформы, риг, shape keys, animation data и полный материал. Обменный FBX/GLB не эквивалентен .blend; экспорт только явно запрошенный, со списком ограничений и статусом exported_NOT_VERIFIED. Interchange roundtrip не реализован и не заявлен пройденным.
- Обработка mesh objects по одному. Никакого join/remove doubles на оригиналах. Данные исходных мешей/материалов копируются перед изменениями; оригинальные файлы никогда не перезаписываются.
- Существующие UV сохраняются. Новая UV-карта добавляется; источники, использующие implicit UV, фиксируются на старой карте. Нормали перепекаются через Cycles NORMAL в новый tangent basis, а не через Emit. Константы Principled не подменяются; карта на каждый используемый linked-канал. Чистый цвет/процедурная модель без UV тоже допустимы.
- Сложные поверхности Mix Shader/Volume/Displacement, анимированные shading dependencies и неподдерживаемые node dependencies блокируются до изменения UV. Отказ — не успешная обработка.
- Защищаются authored seams, sharp edges, material boundaries и сильные диэдральные углы. Связные области и пороги по площади считаются локально. Смежность поддерживает polygons любой степени, а не F×3.
- Кандидаты: несглаженная геометрия и ограниченный по измеренной плотности сглаженный прокси. Слияние сохраняет χ-гейт. PCA-разрез остаётся; после него нужны проверки границ/топологии и UV. Дефолт MINIMUM_STRETCH не меняется.
- Автоматический выбор сравнивает flips/degenerate UV, overlap, площадь, CV и фрагментацию. Если доказанного улучшения нет — оставить исходную UV и материалы, не выполнять лишний resampling. Для модели без UV неудача всех кандидатов — ошибка.
- Адаптивное разрешение ограничивается явным бюджетом; не снижать исходное разрешение молча. Упаковка учитывает bleed. Отчёт перечисляет выбранный кандидат/причины отказа/фактические параметры.
- Native roundtrip QA: объекты/родители/матрицы, topology+positions, material indices, дополнительные UV, кости, веса, shape keys, actions. Любой сбой даёт ненулевой exit code. Не выдавать сохранение .blend за проверку Unity.
- Batch пропускает только успешный отчёт текущей версии с совпавшим fingerprint и существующими outputs; старый файл отчёта не означает успех.

## Ограничения работ
Не запускать Play Mode, скриншоты или автоматический массовый ребейк библиотеки. Не менять Unity сцены/префабы/материалы. Не коммитить _reports, _work или Generated_Models. Unity import, runtime и визуальное принятие: NOT RUN.
