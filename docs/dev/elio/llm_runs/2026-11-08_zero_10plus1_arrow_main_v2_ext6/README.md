**1 победа / 1 ничья / 4 поражения**, но **3 игры из 6 contaminated**:

- **715** — DeepSeek дважды выбрал `displace` нулём (правила §7 разрешают оттеснение только военной фигуре). `applyMove` при оттеснении чистит клетку атакующего, но не ставит его на клетку нуля → фигура исчезает с доски, нуль оказывается на двух клетках. 7 integrity-ошибок.
- **716** — ИИ Плюсов увёл Линейного `P-L1` за доску на `(-2,-4)`; `legalMoves` для одношаговых фигур не проверяет `isValidCell`. Линейный стал «призраком»: жив, но вне доски; партия дошла до ничьей.
- **717** — DeepSeek дважды выбрал `displace` нулём; та же порча доски (13 integrity-ошибок). Победа Нулей по удержанию **не считается доказательством** доктрины.

**Чистая подвыборка: 714, 718, 719 → 0 побед / 0 ничьих / 3 поражения.** Единственная чистая победа v2 остаётся в 711 (пилот v2).
