## 1. Факты из логов (почему дальше без этого никак)

* `graph-fail no-path discs=2-3` при валидных гейтах (`layer-empty` 0):
  рёбра рвутся о то, чего нет в дисках, — меши-скалы и 3D-рельеф между дисками.
* Кейс 0021 (лог 140332): детур 90 с к tangent-точке → скала у точки →
  возврат через старт → стена → hover/recovery/scatter. Точка была «у диска»,
  скала — за радиусом диска.
* Кластер ProfileY≈−419 летит у нижней кромки рельефа: 2D-диски слепы
  к склонам между собой.
* Всё реактивное (валидация точек, slow-replan, divert) терминирует гринд,
  но не убирает детуры-в-никуда: план изначально не знает мешей.

## 2. Решение: бейк мешей в диски PeakRegistry

При `PeakRegistry.Build()` (server-only, один раз) дополнительно сканируем
меши-препятствия сцены:

* кандидаты: активные `MeshCollider` (non-convex тоже — для диска выпуклость
  не нужна, только XZ-габарит) с XZ-диагональю bounds ≥ `meshMinSpan`
  (дефолт 200 м — мелочь добирает лидар);
* диск: центр = bounds.center (XZ), радиус = диагональ XZ / 2 × `meshRadiusPad`
  (дефолт 1.2), верх = bounds.max.y;
* блокировка отрезка: как у пиков, но условие высоты — верх диска, а не вершина:
  `discTop < profileY - margin` → не препятствие (пролёт выше козырька — чисто);
* граф/касательные/IsInsideDisc работают без изменений (единая модель дисков).

## 3. Floating Origin

Диски пиков FO-safe (доли heightmap + живой резолв через трансформ террейна).
Меши едут вместе с корнями сцен → хранить МИРОВЫЕ центры на момент бейка
НЕЛЬЗЯ (протухнут при F8). Варианты:

* **A (рекомендован):** хранить ссылку на Transform меша + локальный оффсет
  (центр/радиус/верх в локальных координатах родителя сцены), мир — резолвом
  вживую каждый `FindBlockingDisc`/`Collect` (паттерн PeakRegistry/ворота).
  Сдвиг не нужен вообще. Цена: резолв десятков трансформов на вызов —
  кэшировать world-центры с инвалидацией по `CumulativeRebaseFrame`
  (статический счётчик слайса уже есть).
* **B:** мировые центры + `PeakRegistry.ApplyRebaseTranslation` + хук
  в `ShiftNpcShipNav` (прецедент — `TrafficManager`). Проще, но ещё один
  участник слайса и риск рассинхрона при позднем спавне.

## 4. Что НЕ трогаем

* Лидар/WallFollow/scatter/divert — остаются страховкой и последней милей.
* Лор вертикали: диски только латеральные, перелётов нет.
* Террейн-ветка PeakRegistry — без изменений (два источника, один интерфейс).
* `useRouteGraph` kill-switch покрывает и меши (нет дисков → legacy как раньше).

1. `graph-fail no-path` падает в разы; `how=graphN` растёт; детуры ведут
   вокруг мешей (видно по `tgt=` + BEAT-трекам).
2. Кейс 0021 не повторяется: план изначально огибает скалу-меш.
3. F8 после бейка: диски на месте (0 errors, пролёты как до).
4. Console → 0 errors; `PeakRegistry built: N peaks + M meshes` в консоли сервера.
