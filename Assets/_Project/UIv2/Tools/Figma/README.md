# Figma Free (Reserve) — UIv2

Figma используется как резервный дизайн-инструмент, если FigCraft не покрывает нужды.

## Workflow (Figma Free)
1. Используйте drafts (неограниченные) для большинства дизайнов.
2. Держите 3 team files для активных коллаборативных/библиотечных файлов.
3. Официальный UI Toolkit Connector (опционально): Window → UI Toolkit → Connector for Figma.
4. Vendored fallback: FigmaToUnity (open source) — конвертация Figma → UXML/USS.
5. Manual polish checklist: шрифты, иконки, bindings, RTL.

## Ограничения Figma Free
- 3 файла в командной папке (drafts не считаются).
- Нет Team Library (общие компоненты).
- Dev Mode расширенный — только платные.
- История версий — 30 дней.
