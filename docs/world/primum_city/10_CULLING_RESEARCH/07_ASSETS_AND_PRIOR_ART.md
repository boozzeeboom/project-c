# 07. Ассеты и индустриальная практика: что брать, чему учиться

**Дата:** 2026-10-30 · **Источники:** `B_ASSET_LANDSCAPE.md` (цены/версии проверены 30.10.2026),
`E_OPENWORLD_PRIOR_ART.md` (кейсы и цифры).
**Коротко:** покупать готовый culling-ассет не нужно; индустрия подтверждает наш путь «склейка задаёт
единицу отсечения + GPU-путь + бюджеты теней/дистанции», а не «отменить склейку и включить один ассет».

## 2. Индустриальная практика: чему учиться

### 2.1 Проверенные цифры кадров (PC)

| Игра | Draw calls/кадр | Что важно |
|---|---|---|
| GTA V (2015, D3D11) | **4 155** | G-Buffer ≈1 900, CSM ≈1 000 (4 каскада), planar reflection 650; culling+LOD в compute |
| DOOM 2016 (Vulkan) | **1 331** | Umbra + GPU occlusion queries поверх; статические карты теней кэшируются |

Вывод: ориентир L0 для нас — **1–3 тыс.** DC, а не «≤120». Бюджет 120 — это L1/L2 (HLOD/импостор).

### 2.2 Принципы, которые подтверждаются практикой

1. **Склейка задаёт единицу отсечения.** Склеил по ячейке — отсекаешь ячейкой; склеил «город по
   материалу» — отсекать нечего. UE HLOD/World Partition, Creation precombine — по ячейкам.
2. **Уровни гранулярности по дистанции:** ближний — независимые/инстансированные объекты, средний —
   HLOD по блокам, дальний — 1–2 прокси/импостора. Это не «или merge, или culling».
3. **Число объектов не должно быть числом draw calls** — GPU-driven (GRD/BRG/Nanite/indirect).
4. **Тени — множитель числа объектов:** `DC ≈ N_visible × (1 + K каскадов)`. Мелкие кастеры резать по
   дистанции (GTA V CSM ≈1 000 из 4 155; DOOM кэширует статику).
5. **Двери/мелкий интерактив** — инстансинг + тени off на дистанции + LOD/«proxy door»; порталы для
   уличных дверей почти не применяют.
6. **Baked PVS** (Umbra/PreVis) — мощно, но жёстко: правка ячейки ломает данные, мир должен быть
   статичен, координаты — мировые. Для FO это принципиально не наш путь.
7. **FO-safe:** frame-local окклюзия (Hi-Z, occlusion queries), локальные координаты ячеек, никакого
   world-space bake.

## 3. Что это значит для нас

1. **Не покупать** culling-ассет: ROI ниже, чем у low-code + GRD; риск «не заведётся на Unity 6» высокий.
2. **Не откатывать merge**: индустрия подтверждает «merge by cell», а не «no merge».
3. **Не запекать**: Umbra/PVS в мировых координатах несовместимы с FO; только frame-local или
   локальные координаты ячеек.
4. **Делать**: (а) двери — инстансинг/тени/дистанция; (б) GRD + Hi-Z; (в) блоки/HLOD на дистанции;
   (г) свой тонкий директор для бюджетов/мультикамеры/кораблей.
5. **Покупать только если** появится ассет с явной поддержкой Unity 6.5/URP 17.5, non-static объектов,
   multi-scene/FO и отдельного shadow-caster culling — сейчас таких нет.
