# Автоматический Humanoid-риг сгенерированных персонажей

## Пилот

- Модель: `PC_Char_Adjudicator_Female_APOSE_v01`.
- Вход: `Assets/Generated_Models_Retopo/01_Characters/Archetypes/PC_Char_Adjudicator_Female_APOSE_v01/PC_Char_Adjudicator_Female_APOSE_v01_Retopo.fbx`.
- Замерено после импорта: 39 998 треугольников, 19 988 вершин, UVMap и BaseColor присутствуют, исходных групп весов нет.
- Эталон именования и иерархии: `Assets/Generated_Models/_Legacy_PreAugust/Character_17866748877224/BLENDER/1_5.fbx`.
- Целевая высота пилота: 1,7837 м, подошвы на Z=0, ориентация лица -Y в Blender. Для серии высоту нужно будет брать из профиля персонажа, а не принудительно делать всех одинаковыми.

## Почему прежний результат отбракован

Прежний `rig_character.py` проецировал кисть эталона и затем использовал её как fallback даже при неудовлетворительном измерении. В отчёте пилота большинство контрольных точек пальцев находились вне поверхности. Нулевое число невзвешенных вершин не доказывает правильность скелета.

## Пайплайн

1. Импортировать FBX без изменения исходника; зафиксировать геометрию, материалы, UV и трансформы.
2. Нормализовать ориентацию, положение подошв и масштаб. Применить трансформы до построения костей.
3. Найти суставы тела по мешу. Auto-Rig Pro в итоговый алгоритм не входит: его Smart-детектор на пилоте создал 334 кости и неверно измерил кисть.
4. Кисть разбивать на отдельные кандидаты пальцев по геодезическим путям от запястья. Не назначать имена по принципу «первые пять». Для каждой цепочки измерять длину, радиус, непрерывность, направление и пребывание внутри меша.
5. Выбирать ровно пять анатомических цепочек: большой палец отдельно по отгибу и положению относительно ладони; указательный/средний/безымянный/мизинец — поднабором из четырёх по эталонным паттернам длины и поперечного положения. Лишние цепочки не получают Humanoid-костей и попадают в отчёт.
6. Если уверенного набора из пяти пальцев нет, остановить обработку персонажа со статусом `REVIEW_HANDS`; не подставлять эталонные пальцы скрытно.
7. Построить компактный скелет с именами эталона `B-*`, 50 deforming bones и корневым transform `B-hips`, без лицевых костей и служебных контроллеров ARP.
8. Для кистей использовать детерминированные веса до измеренных сегментов. Вершины лишнего пальца привязываются к ближайшему выбранному пальцу, а не остаются неподвижными. Не смешивать веса между соседними пальцами.
9. Нормализовать сумму весов до 1 и ограничить четырьмя влияниями на вершину. Невзвешенные вершины, нулевые кости, сумма вне допуска и более четырёх влияний блокируют экспорт.
10. Проверить rest pose и деформационные позы: плечо/предплечье, бедро/голень, все пальцы обеих кистей. Сохранять общие рендеры, изолированные кисти и боковой вид сгиба.
11. Экспортировать новый FBX без перезаписи прежней неудачной попытки. В Unity настроить ModelImporter: Humanoid и Create From This Model; mapping `B-*` взять из проверенного эталона, затем проверить `isValid`/`isHuman`.

## Проверка пользователем

1. Открыть `_Rigged_Humanoid.fbx` в Project и в Rig убедиться: Animation Type = Humanoid, Avatar Definition = Create From This Model.
2. Перетащить модель в пустую тестовую сцену, не заменяя текущего рабочего персонажа.
3. В Avatar Configuration проверить зелёный mapping тела и всех пальцев.
4. Вручную согнуть плечо, предплечье, бедро, голень и каждый палец обеих кистей; отдельно проверить, что дополнительная геометрия кисти следует за ближайшим пальцем.
5. Проверить рост и подошвы относительно эталона `1_5.fbx`. Play Mode и Build агентом не запускаются.

## Масштабирование на каталог

- Общий скелет и правила одинаковы для 40k, 12k и raw; измерения выполняются заново по каждому мешу.
- LOD связываются с одним скелетом/Avatar только после подтверждения совпадения пропорций.
- Скрипт уже принимает `--input`, `--out`, `--report`, `--renders`, `--blend` и `--no-mirror`. Следующий этап — отдельный 12k-пилот, затем обёртка пакетного обхода каталога с одним JSON на персонажа и остановкой ошибочных моделей без нового FBX.
- До пакетного запуска нужны пороги высоты из профилей персонажей и отдельная проверка репрезентативных несимметричных моделей.
