# T-SHIP-FIX12 — мелочи визуалов/контроллера/конфигов (только безопасное)

> Тикет: `T-SHIP-FIX12` (P1, фаза C). Дата: 2026-09-18. Статус: **ИСПРАВЛЕНО ЧАСТИЧНО (код + дока)**.
> Принцип тикета: каждый подпункт перепроверен; чиню только однозначное; сомнительное —
> в отложенные с причиной. Тесты — за пользователем (реестр).

## Исправлено (9 — F6 откачен, см. ниже; все проверены чтением кода перед правкой)

- **F1. ShipPartShake — застывшая поза при OFF.** Ранний выход без сброса оставлял смещение
  до 2см/0.5°. Фикс: snap к базовой позе + обнуление smooth при выключенном двигателе
  и при уходе ниже порога (инвариант «нет тяги = базовая поза», чисто визуал).
- **F2. EngineThrusterVisual — застывший deflection при OFF.** Ранний выход оставлял
  `_currentAngle`. Фикс: вместо выхода — нулевые входы (угол/обороты плавно гаснут через SmoothDamp).
- **F3. EngineThrusterVisual — магическая 0.3f (`:164`).** Новое `[SerializeField] _rpmSmoothTime = 0.3f`,
  значение то же (поведение не меняется).
- **F4. EngineThrusterVisual — yaw-фолбэк по мировой Y (`:148`).** При крене/тангаже врал.
  Фикс: `InverseTransformDirection` → локальная Y (визуал, безопасно).
- **F5. `ShipPersistentId` — геттер с сайд-эффектом (`:93`).** Мутировал сериализованное поле.
  Фикс: чистый геттер (поле используется только здесь, проверено grep; значение то же).
- **F6. `IsGrounded` — НЕ УДАЛЁН (откат).** Первичная проверка grep дала 0 использований —
  неверно: `PlayerStateMachine.Disembark:113` использует его как гейт выхода
  (`!IsGrounded && speed>2 → запрет`). Удаление сломало компиляцию (CS1061 пойман консолью),
  строка возвращена как была. Правильный фикс (маска + длина) МЕНЯЕТ гейт выхода —
  это геймдизайн-решение, отдельным тикетом. Урок: удаления проверять поиском по диску (bash),
  не только grep-инструментом.
- **F7. `ShipDamageConfig`:** `verboseLogging` дефолт `true` → `false` (прод-спам на каждый удар;
  `ShipDamage.asset` отсутствует — живут in-memory дефолты, т.е. спам реален);
  `GetMaxHull` default → `Warning` вместо молчания; удалён `repairCostCredits`
  (deprecated+hidden, 0 использований — проверено grep).
- **F8. `RepairManager` — паритет с консолью:** триггер `tag || CharacterController`
  (регистрация duplicate-safe через `Contains`, проверено) + добавлен `OnDisable→Unregister`
  (был только у консоли).
- **F9. `ShipCargoConsole.InstanceId` — `IsSpawned`-гард:** до спавна все корабли давали
  `"0_cargo"; теперь — уникальное имя объекта (регистрация только в рантайме, но инвариант чище).
- **F10. `ShipModule` — удалены `meziyDuration/meziyCooldown`.** 0 использований
  (активатор живёт на своих `overheatThreshold/cooldownDuration`, проверено grep);
  поля-сорняки в инспекторе SO больше не смущают. Значения в ассетах игнорируются движком.

## Отложено (сознательно НЕ трогаю — нужно решение/плей-тест, неочевидно)

- **D1. Физика вкуса:** `ClampPitchAngle *10f` без dt/массы, `yaw/pitchForce` vs массы 8–20т,
  `maxLiftForce` размерность/коммент. Работает, точные цифры — только плей-тестом.
  Кандидат: баланс-тикет с замерами.
- **D2. `AltitudeCorridorData.GetStatus` асимметрия** (Danger сразу снизу, зазор сверху).
  Возможно задумано (верх — «мягкий потолок»). Нужен ответ дизайна, не код.
- **D3. `KeyRodInstanceWorld` AutoSave на мутацию + `instanceId` не персистится.**
  Персистентный дизайн + порядок инициализации — отдельный тикет.
- **D4. `ShipCargoVisual` слоты-vs-ящики.** Визуальная математика — только с игровым чеком.
- **D5. Источник thrust в визуалах (reader vs RB).** Принято дизайном (пилот/фолбэк), только визуал.
- **D6. Install не списывает кредиты.** Баланс (отмечено ещё в FIX03).
