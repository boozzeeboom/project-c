## 0. Главный ответ (TL;DR)

1. **Кадр — это кадр дверей.** Двери дают **17 766 из 21 118** draw calls (84 %) в конфиге
   shadow 250/1 и **22 027 из 26 981** (82 %) в 1000/2. При этом двери — <10 % треугольников.
   Стоимость двери — `material slots × проходы`: 2–3 MeshRenderer, **5.19 material slot** на инстанс,
   ×2–3 прохода (opaque + depth-prepass + каскады теней).
2. **Склейка города не была ошибкой — ошибкой была бы её отмена.** Без склейки город даёт
   **~20 694 slots** вместо 1 806 → **25–40 тыс. draw calls** (регресс ×1.2–1.9). Склейка — необходимость
   для CPU/редактора. Но её **гранулярность** (чанк × материал, AABB медиана **130 м**) слишком
   крупная для окклюзии/LOD: лечится пере-склейкой по **блоку/дому 10–30 м**, а не расклейкой.
3. **Корабли — второй источник draw calls, а не «уже склеенная мелочь»** (наш прежний вывод был
   неверен: YAML-парс не видел вложенный FBX). Живой аудит: тяжёлый корабль = **973 MR / 973 slot**
   (light 428, medium 118, 20 NPC ×6); в сцене **23 корабля = 1 639 MR = 18.4 %** рендереров при 2 %
   треугольников. Нужен edit-time мерж по материалам/ячейкам (973 → ~92 slot) + вынос 250 коллайдеров
   и 9 дверей из FBX-инстанса. «Не клеить, а куллить» — неверно.
4. **Umbra — закрытая ветка:** 6 бейков упали, данные world-space, static-флаги запрещены FO,
   публичного runtime-API данных окклюзии нет. Первый авто-ребейз FO — **≈56 км**, дальше
   0.26–1.5 км каждые ~35 с; любой baked world-space PVS умирает.
5. **Главный выигрыш — дешёвый и двойной:** (а) low-code бюджет дверей (слой + `layerCullDistances` +
   тени off по дистанции) — **2–4 дня**, ожидание **26 981 → 5 000–9 000** DC (−67…−81 %);
   (б) **пилот кораблей — только `Ship_havyII_base`**: тяжёлый **973 MR → ~620 slot** за 1–2 дня
   (P3 → ~92 slot); остальные корабли — future scale-out после зелёного пилота, в этих операциях
   не трогаются.
6. **GPU-путь сработал:** GRD включён 31.10 (`BrgStripping=2`, mode=1); P1 **6 400 → 3 031 DC**.
   GPU occlusion **≈0**; DC упирается в unique (mesh,material)-пары. **Stage 4b/4c:** бенч 2 423,
   реальный компонент после фикса камер — **2 394 DC**; **Stage 6 VisibilityDirector — 2 378/2 372**
   (реальная игра 2 362), culling ≈1.3–1.7 мс. **Stage 7 (HLOD/L1/L2) — L1 46 / L2 2 DC**, L0 2 341;
   **Stage 8 — двери L0 режутся по 150 м: L0 2 229**, финальная приёмка дала 2 235 и закрыла T-CULL01.
   Старые 26 981 / 6 094 / 3 031 — исторические.
7. **Свой код нужен, но не «свой окклюжн-движок»:** тонкий **Visibility/Budget Director** поверх
   engine-куллинга (иерархия групп, мультикамерный union, бюджеты теней, двери/корабли, гистерезис,
   FO-safe, ≤2 мс). Свой GPU-driven BRG — 6–10 недель дубля engine, не первый шаг.
8. **Покупать ассеты не нужно:** ни один не декларирует Unity 6.x/URP 17.5; все куллят готовые
   рендереры, а наша боль — число слотов дверей, которое решается инстансингом/GRD (двери уже делят
   меши: 72 пары). Perfect Culling — только как измеритель потолка; GPU Instancer Pro — для пропсов,
   не для дверей, с риском FO.
9. **Бюджет «≤120 DC (L0)» нереалистичен** (GTA V — 4 155, DOOM 2016 — 1 331 DC/кадр). Предложение:
   **L0 1.5–3k**, L1 ≤500 (HLOD), L2 ≤10 (импостор); culling CPU ≤2 мс.
10. **Ближайшие 3 шага:** (а) решение по теням дверей; (б) **P0 корабли** — вынести 250 коллайдеров и
    9 дверей из FBX (0.5 дня) + P1 greeble-мерж; (в) E0/E8 — baseline на реальном far 30/60/120 км и
    4 точках; затем E1 low-code и GRD-пилот. Пере-грануляция города — только после GRD.

## 2. Ответы на вопросы заказчика

| Вопрос | Ответ |
|---|---|
| «Можно было не склеивать город?» | Нет: без GPU-пути это ×1.2–1.9 DC и снова медленный редактор. Правильно — **B2 (дом × материал только ≥1 м)** и только после GRD, а не отменять. |
| «Можно то же с тяжёлыми кораблями?» | **Да, но не «куллить».** Тяжёлый корабль = 973 MR; мерж по материалам/ячейкам (P1 973→~620, P3 →~92) + LODGroup; P0 — вынести 250 коллайдеров/9 дверей из FBX. |
| «Можем написать лучше, чем ассеты?» | Да, но лучший собственный код — **тонкий директор бюджетов/групп**, а не свой GPU-куллер. Свой BRG — 6–10 недель, 80 % уже в engine. |
| «Рисовать только то, куда смотрит игрок?» | Достижимо: frustum + GPU-окклюзия + distance/shadow-бюджеты. Baked PVS не нужен; окклюзия «за стеной» появится с GRD. |
| «Что даст больше всего?» | Двери (84 % DC) и корабли (18.4 % рендереров): двери — слой/тени/дистанция; корабли — мерж/LOD. Город — после GRD. |
