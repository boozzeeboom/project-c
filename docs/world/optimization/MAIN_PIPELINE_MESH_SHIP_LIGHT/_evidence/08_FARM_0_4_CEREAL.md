## 3. Двери: 35 инстансов, 6 префабов [F]

Проёмы фермы крупные: 1.05 × 2.12 … 5.30 × 4.77 м. Правило выбора — как на 0-3: сначала по числу створок,
затем минимизация `(w + h)` при равномерном подгоне `min(openW/prefabW, openH/prefabH)`, ограничение `0.5…1.8`.
Масштаб неравномерным не делался ни разу.

| Префаб | Инстансов | Масштабы |
|---|---:|---|
| `PM_DOOR_GATE_A` | 14 | 0.807 |
| `PM_DOOR_GATE_B` | 7 | 1.201 ×3, 0.891 ×2, 0.874, 0.880 |
| `PM_DOOR_SINGLE_WIDE_A` | 7 | 1.590 ×2, 1.156 ×5 |
| `PM_DOOR_PALACE_DOUBLE_C` | 4 | 1.668 |
| `PM_DOOR_SINGLE_ARCH_C` | 2 | 1.325 |
| `PM_DOOR_SINGLE_PANEL_B` | 1 | 0.986 |

- Позиция инстанса = `(bounds.center.x, bounds.min.y, bounds.center.z)` исходной створки; поворот `identity`
  при проёме по X, `Euler(0, 90, 0)` при проёме по Z. По всем 35 дверям позиция совпала с исходным проёмом **точно**
  (сверка с бэкапом, расхождение 0.00 м).
- Контроль переразмера: `placedW/openW` и `placedH/openH` ≤ 1.02 у **всех 35** дверей (переразмеренных — **0**).
  Наименьшее заполнение: `ARCH_GATE_E/W` — 1.000 по ширине и **0.733** по высоте (3.50 м против 4.77 м проёма),
  `MILL/WH_GATE` — **0.877** по ширине (4.65 против 5.30 м). Это цена 11 фиксированных префабов: следующий по высоте
  кандидат (`PM_DOOR_GATE_B`, 3.21 м) хуже, неравномерный масштаб запрещён.
- Исходная дверная геометрия снята: **109 рендереров / 5 496 верт**. Остатков (`*_LEAF`, `*_HINGES`, `*_HANDLES`)
  вне группы дверей — **0**.
- **4 створки карго-лифтов** (`CARGO_LIFT_*_GATE_{TOP,BOTTOM}_LEAF`, 96 верт) **не заменялись и не удалялись**:
  это створки шахты лифта без петель и ручек, часть механизма, а не hinged-дверь. Они вошли в merged-батчи блока
  `61_TRANSITIONS` (сумма верт статики блока совпадает с источником: 4 848 = 4 848).
- Все 35 инстансов — слой **10 `PRIMUM_DOORS`**, `DoorController` жив (35), статические флаги не ставились.

- **Префаб не размещён** в `WorldScene_0_0` под `WorldRoot_0_0/Primum_farms/<имя>` (`SETTLEMENTS.md` §7.7 шаг 1).
  Размещение и сохранение сцены — решение пользователя. Двери фермы в текущем Stage 8 bench не участвовали.
- **Нет визуальной Play Mode-приёмки**: посадка дверей в проём, открытие/закрытие, ночной режим ламп, швы слияния.

  (≈0.33 м на сторону). Ограничение набора из 11 фиксированных префабов, а не ошибка посадки.

- Префаб и `.meta` вне git (`.gitignore:153`, `:182`); в коммит идут только merged `.asset` и этот отчёт.
- Проход не писал пер-объектный манифест `MF_* → M_PC_*` и не оставил консольного лога (работа через `execute_code`),
  поэтому соответствие материалов по объектам сейчас не воспроизводимо; геометрический результат сбалансирован точно.
