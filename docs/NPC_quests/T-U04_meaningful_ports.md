# T-U04: Осмысленные порты

**Дата:** 2026-07-22
**Файл:** `QuestNodeGraphView.cs`
**Слой:** 0 — Фундамент
**Зависит от:** T-U01

## Что сделано

### Имена портов
Было: `port.portName = ""` — все порты неразличимы.
Стало: параметры `AddPorts` с читаемыми именами по умолчанию:
- Входной порт: `"← Prev"` (серый)
- Выходной порт: `"→ Next"` (зелёный)

### Цветовое кодирование
- Зелёный (`0.35, 0.70, 0.35`) — выходные порты (success flow)
- Серый (`0.55, 0.55, 0.55`) — входные порты (default)

### Расширяемость
Метод `AddPorts` принимает опциональные `inputName`/`outputName` — в T-U05/T-U08 можно задать «True»/«False» для condition-нод.
