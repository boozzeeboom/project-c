## 2. Admission gates

Участник допускается только если одновременно подтверждены все шесть независимых условий:

1. `IdentityReviewed` — identity source reviewed.
2. `ExplicitPolicyReviewed` — inclusion/exclusion policy reviewed.
3. `CatalogSpatial` — catalog explicitly declares spatial eligibility.
4. `RuntimeAdapterReady` — concrete runtime adapter exists and is ready.
5. `RuntimeProofComplete` — required runtime behavior is demonstrated.
6. `RollbackReady` — immutable snapshot/restore guarantee exists.

Политика применяется одинаково к `SHIP_ROOT` и `NETWORK_GAMEPLAY_ROOT`. Catalog identity match, `treatment=Unmanaged`, `spatial=false` или наличие NetworkObject не дают automatic admission.

## 3. Проверки

`ProjectC/World/Floating Origin/Validate Participant Admission Policy`

Выполнены десять pure checks:

- ready evidence admits a reviewed participant;
- missing identity review fails closed;
- missing explicit policy review fails closed;
- non-spatial catalog entry fails closed;
- missing runtime adapter fails closed;
- incomplete runtime proof fails closed;
- missing rollback readiness fails closed;
- failure precedence is deterministic;
- Network gameplay roots require every gate;
- admission does not mutate entry identity or evidence.
