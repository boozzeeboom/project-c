# T-FO09J — Персистенция позиции: спавн вне фрейма 100000

Date: 2026-09-14. Жалоба (ф10_32): побегал → перезаход → всегда точка
спавна, не старая позиция. Проверено многократно.

## Диагноз

- В логе: `PilotSpawnLegacy: outside pilot frame, default spawn`.
- Сейв прямо сейчас: игрок `(15.5,-57.8,1.5)` (пост-сдвиговые локалы),
  кумулятив `(-359424,-23040,-361728)` frame=2. Коррекция
  `p − offset` даёт скорректированную точку **359439** — origin вырос
  до ~359км за сессии полётов (каждая сессия стартует с origin 0 и копит
  заново в сейв). Пилотный фрейм `maxLocal=100000` → проекция невозможна
  → тихий fallback на дефолт. Повторяется всегда, пока origin > 100км.
- Математика sibling (коррекция) корректна; сломан только капасити
  фрейма спавна. Полноценный перенос origin между сессиями (initial
  rebase контента при загрузке) — отдельный крупный тикет: статический
  контент (YAML) выровнен под origin-0 старт, трогать нельзя.

## Решение (минимальное, архитектуру не меняет)

1. `GlobalMotionPilotSpawnSource`: экстент фрейма спавна
   `PilotSpawnFrameExtent = 1000000f` (оба пути — якорь и default).
   Покрывает накопленный origin; `_maxLocalCoordinate` поле оставлено.
2. После спавна автосдвиг сразу переносит origin к игроку
   (транзиентный джиттер ~3см, секунды): `TryAutoRebase` резолвит игрока
   ДО троттлинга (слот не сгорает до спавна) + recover-план 09H-fix
   покрывает внефреймовый фокус.
3. Origin-0 старт, коррекция, fallback'и, deathY — без изменений.
