# Balance — headless-прогоны Эльо

> Здесь лежат **прогоны без LLM**: встроенный ИИ играет все три фракции. Формат — по одной папке на эксперимент, чтобы строить графики баланса. Версия ИИ указана в `results.json`.

## Структура

```
balance/
  README.md
  _tools/
    elio_headless_matrix.js   — матрица 3×2×3, seeded RNG, integrity-guard
  YYYY-MM-DD_<эксперимент>/
    config.json               — движок, ИИ, seed, варианты
    results.json              — summary по 18 вариантам + games_detail (1800 строк)
    analysis.md               — разбор
```

## Запуск

```bash
# 100 игр на каждую из 18 вариаций (3 порядка × 2 типа × 3 пешки)
N=100 SEED=20261108 node _tools/elio_headless_matrix.js

# 6 тактических сценариев борьбы за «Ц»
node _tools/elio_ai_center_test.js
```

- `N` — игр на вариацию; `SEED` — база seed; `OUT_DIR` — куда писать `results.json`.
- Каждая игра получает свой seed (`base + variant*100003 + game*7919`), поэтому прогон воспроизводим.
- `integrity-guard` после каждого действия: off-board, дубли/несвязанные клетки, залипшие щиты; при нарушении игра помечается `contaminated` и останавливается.
- `passRule` — `random` (канон); `cycleDir` — `forward`. `repeat`/`back`/`reverse` в матрицу не входят.

## Как строить прогресс

- `results.json` каждого прогона: `summary` по вариантам + `games_detail` (по одной строке на игру).
- Для графиков: ось X — вариант/режим, ось Y — winrate P/M/Z, средняя длина, line deaths, center entered %.
- 10 фигур — канон; 10+1/15 — отдельная серия с пометкой «тест».
- Не смешивать contaminated/stuck с чистыми; в этом прогоне их 0.

## Важно

- 10 фигур — канон; **10+1 (p1)** и **15 (p5)** — тест-варианты, не канон.
- «Цикл» — исторический режим; «Стрелка» — соревновательный эталон; «Передача» — тест.
- 100 игр на вариант — это ±~5–10 п.п. по winrate; для тонких выводов нужна выборка больше.
- **PassTo-фикс:** 100×18 pass-строки получены **до** фикса AI passTo; 400×2 Pass+Main p1 — после. Не смешивать.
- 400×2 показал: Pass+Main p1 — 27.25/31/40.5, Arrow+Main p5 — 25.25/34.75/40; оба zero-favored ~40 %. 100-игровые 29/33/36 и 32/31/37 были шумом/багом.
