### 9.2. VisibilityDirector

- Авто-бутстрап на скрытом `ViewDistanceRuntime` (`DontDestroyOnLoad`), **только Play Mode**.
- **1 000 групп, 1 147 направляемых рендереров**, union = 1 камера (`ThirdPersonCamera_0`), тик 3 Гц (0.33 с),
  средний 0.90 мс, пик 4.07 мс на телепорте.
- Все политики — через **единственное свойство `forceRenderingOff`**: под-пиксельный cull (2 px / 12 %),
  HLOD L0→L1 (3 000 м / 10 %), L1→L2 (12 000 м / 10 %), двери (150 м → 135 м), ночь (`_PrimumHlodNight`).
- **Новый контент ловится только авто-обнаружением по точному имени/иерархии** (API регистрации нет):
  дети `PRIMUM` → `Chunk→House`, дети `Primum_farms` → `Farm`, корни `Secund/Tertius/Quartus` → `Satellite`,
  `*_DOORS`/`*_LIGHTS` → наблюдение, `RuinsValleys` → наблюдение. Любой другой корень = `Misc` — **не куллится**.
- Нельзя: писать `forceRenderingOff`, переименовывать корни, гасить контент через `SetActive`,
  ставить `forceRenderingOff` руками до старта, добавлять второй HLOD-корень.

### 9.3. HLOD L1/L2

| Параметр | Значение |
|---|---|
| L1-единица | **ребёнок `PRIMUM`** (имя = имя блока); 23 блока из 26 детей |
| L1-бейк | 859 рендереров / 5 407 574 тр. → **266 794 тр. (−95.1 %)**; интерьеры вырезаны лучами (41 направление), мелочь <0.25 м удалена; 1 меш × 1 материал на блок |
| L1-стоимость | **46 DC** (≈**2 DC/блок**); 29.31 МБ L1 + 2×10.66 МБ атласов = 50.65 МБ / 29 файлов |
| L1-бейк время | ≈28 с (23 блока + L2) |
| L2 | 8 азимутов × 4 высоты, атлас 4096×1024 DXT5, **2 DC** |
| Детерминизм | `bakeHash 5253f70a…`, `FILES_IDENTICAL 29`, `mismatches=0` |
| Команды | `Project C → Culling → Stage 7 HLOD → Bake All Blocks + L2` / `Rebake Determinism Check` |
| Входит | **только город**; фермы/спутники/руины/корабли — **нет** |

**Каждый новый блок в `PRIMUM` = перепечь L1+L2.** Не перепечь = новый контент живёт только <3 км (L1/L2 показывают
старый силуэт); рендереры, спрятанные в редакторе (`enabled=false`), в L1 не попадут и «исчезнут» на 3–12 км.

### 9.4. Пределы ×100 (почему нельзя просто «добавить блоки»)

| Метрика | Сейчас | Предел/формула | ×10 | ×100 |
|---|---:|---|---:|---:|
| Блоков HLOD | 23 | = детей `PRIMUM`; жёсткого потолка в коде нет | 230 | 2 300 |
| L1 DC | 46 | **2 DC × блоки**; гейт ≤500 → **≈250 блоков** | 460 (на грани) | **4 600 — провал в 9×** |
| L1-ассеты | 29.31 МБ | 1.27 МБ/блок | 293 МБ | **2.9 ГБ в git** |
| Сцена `WorldScene_0_0` | 60 МБ / 1.54 M строк | один монолит | ≈600 МБ | **≈6 ГБ — не грузится** |
| HLOD в памяти | ≈25 МБ | всё в `Resources`, не выгружается | ≈250 МБ | ≈2.5 ГБ резидентно |
| FO-участники | 61 корень | все активные корни сцены | ≤100 | ≤100 |

**Вывод:** ×100 упирается не в L0-геометрию, а в два места: (1) `2 DC × блоки` — L1-гейт живёт до ~250 блоков,
дальше нужен промежуточный уровень (агломерация 5–10 блоков в один L1-меш) или L1-каскад; (2) `Resources`-манифест,
тянущий весь HLOD всегда — при большом объёме понадобятся Addressables/сцены.
**Решение 2026-11-01:** весь контент — в `WorldScene_0_0`; архитектурный вопрос раскладки по сетке 6×4 **не поднимаем**,
пока файл сцены не приблизится к ~100 МБ (сейчас 60 МБ). Монолит — сознательный выбор, а не недоделка.

### 9.5. Правила «новый квартал = …»

1. **Новый квартал = новый ребёнок `PRIMUM`** (= блок = чанк директора), имя
   `PRIMUM_<TYPE>_S<n>_<ZONE>_P<m>_<NN>H`, совпадающее с `PRIMUM_DOORS/<то же имя>`.
   Футпринт 26–228 × 156 м, ≤80 k тр., ≤65 535 верт./меш, join «блок × материал».
2. **1 блок ≈ 2 DC в L1 ≈ 1.27 МБ ассетов.** Бюджет мира: **≤200–250 блоков** (иначе L1 ≤500 не выполняется).
3. **≤~100 корней сцены** (FO-участники); всё держим в `WorldScene_0_0` — следим за размером файла (решение 2026-11-01).
4. **HLOD бейкаем по факту наполнения:** готов ряд/квартал (например, ряд из 10 ферм) → `Bake All Blocks + L2` + determinism.
   Не после каждого блока/ассета; до перепечки новый контент живёт в L0 (<3 км) — это нормально.
5. **Фермы/спутники/руины в HLOD не входят** — при ×100 они дают L0-DC на всех дистанциях; сначала сделать им L1
   по шаблону (бейкер знает только `PRIMUM`).
6. **L2 пересматривать при футпринте >≈5 км** (один квад + атлас перестаёт читаться): 2–4 региональных импостора
   или тайловый атлас.
7. **Перепечка L1+L2 — пачками по факту наполнения** + F8/F9 + `Rebake Determinism Check`.
