# 400×2: Pass+Main (10+1) и Arrow+Main (15 фигур)

## 1. Что прогнали

- **800 партий**: по 400 на каждый вариант, без LLM, ИИ v1.3c, движок v1.3d.
- **Pass+Main, 10+1 C1**: `pawns=1`, лимит 90, `passRule=random`.
- **Arrow+Main, 15 фигур**: `pawns=5`, лимит 120, первый ход пешкой.
- Seeded RNG, integrity-guard, `passTo`-фикс (см. §3).
- Старый прогон без passTo-фикса сохранён как `results_pass_rng_mismatch.json`.

## 4. Найденные ошибки кода и доков

### 4.1. Код: AI passTo mismatch (исправлено)

- `elio_ai.js` `chooseMove`/`afterAction` применяли ход к клону **без** `passTo`; `advanceTurn` выбирал случайного получателя. Затем фактический `E.applyMove` в арене/раннере выбирал **другого** случайного получателя.
- Диагностика: **21 из 40** ходов — цель в оценке ИИ не совпадала с фактической.
- Исправление: один `passTo` на ход; все кандидаты и фактическое применение используют его. Диагностика после фикса: **40/40 совпадений**.
- Влияние на баланс: Pass+Main p1 400 сместился с **29.5/35.75/33.75** (баг) на **27.25/31/40.5** (фикс): Нули +6.75 п.п., Минусы −4.75, Плюсы −2.25.
- Старые pass-результаты (`100×18` pass-строки, `ANALYSIS_11_PIECES` Pass+Main/Pass+Long, `ANALYSIS_15_PIECES` Pass-строки) получены **до** фикса. Их нельзя смешивать с новыми pass-данными.

### 4.4. Доки/правила: pass-передача

- Правила §11.3: игрок **выбирает**, кому передать ход. В headless-тесте ИИ/авто передаёт **случайно** (канон `random`); LLM-арена тоже не управляет `passTo`.
- Pass+Main p1 400 — это **random-pass baseline**, а не проверка стратегической передачи. При выборе человеком/LLM баланс может измениться.
- LLM-арена использует лимит 60, headless — 90. Цифры 10+1 Pass+Main нельзя напрямую сравнивать с LLM-тестом.

### 4.5. Доки/правила: 10+1 и 15 — не канон

- Оба выбранных варианта — тест-варианты. 400 игр не делают их каноном.
- 15 фигур по-прежнему перекошены в Нулей (40–79 % в зависимости от режима); Cycle — 78–79 %.
- 10+1: чистые 400 Pass+Main 27.25/31/40.5; Arrow+Main 100 31/41/27; Arrow+Long 100 27/29/44; Pass+Long 100 26/41/32 — ровного нет.

## 6. Вывод для выбранной комбинации

- **Оба варианта на 400 — zero-favored ~40 %.** 100-игровые 29/33/36 и 32/31/37 были малым шумом (а pass-вариант ещё и смещён багом).
