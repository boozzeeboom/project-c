**Статус:** ✅ Реализовано (сессионно, без персиста)
**Код:**

## 1. Типы и иконки

| Тип | Кнопка | Иконка на карте |
|---|---|---|
| Ориентир | Ориент. | Чернильное кольцо |
| Опасность | Опасн. | Красный треугольник |
| Заметка | Замет. | Чернильный квадрат |
| Цель | Цель | Двойное красное кольцо |

Выбор = красное кольцо 13px. Подпись — чипом справа от иконки (пул 24 Label
поверх painter-слоя, проекция каждый кадр; клики пропускают).

## 2. Постановка

Легенда → «＋ Метка» → панель: 4 типа (подсветка выбранного) + поле
«Название» + подсказка. Клик по карте ставит метку и выходит из режима
(предсказуемо: один клик — одна метка). Пустое название → дефолт по типу
(«Опасно», «Цель»...). Поставленная сразу выбирается.

Клик мимо в обычном режиме = циркуль + снять выбор. Клик по метке (порог
14px, ближайшая) = выбрать. Выбранная видна в подвале:
`✕ опасность: штормовой карман`, там же кнопка «Удалить выбранную».

## 3. Данные и FO

`ChartMark { id, worldPos, type, text, utcSeconds, source }`, `SelectedId` —
якорь будущего пеленга в HUD (следующий слой). Менеджер — DontDestroyOnLoad-
синглтон, поднимается вместе с рекордером. Сдвиг мира: тот же
`ApplyRebaseTranslation`, слайс-метод переименован в `ShiftChartJournal`
(возвращает сумму точек+меток, маркер `ChartTracksShifted (entries=N)`).
