## 2. Где это в сцене

```
WorldRoot_0_0
├── PRIMUM                 ← город (инстанс PRIMUM_CITY.prefab) — НЕ ТРОГАЕМ
├── PRIMUM_DOORS           ← 2 161 префаб двери
└── PRIMUM_COLLIDERS       ← ✅ 7 428 боксов, трансформ = трансформ PRIMUM
    └── <чанк>/
        ├── WALK           ← один GameObject, 9 BoxCollider
        ├── WALL           ← один GameObject, ~200–600 BoxCollider (осевые)
        ├── FLOOR / ROOF
        └── STAIR          ← группы по (yaw,pitch): GameObject с поворотом + N BoxCollider
```

**Почему СОСЕД корня города, а не ребёнок:** всё, что добавлялось внутрь префаб-инстанса `PRIMUM`,
терялось при пересохранении префаба (так пропали `SLAB3` и старый `PRIMUM/COLLIDERS`). Корень
коллайдеров копирует трансформ `PRIMUM` и висит под `WorldRoot_0_0` → **ребейз мира везёт его вместе с
городом**. Если корень города сдвинут/повёрнут — пересобрать коллайдеры (одно меню).

## 3. Откуда геометрия и как считается

Источник — **исходная (несклеенная)** геометрия `PRIMUM_chunks_RAW/*.blend` (23 чанка). Из склеенного
по материалу меша боксы получить нельзя: он охватывает чанк целиком.

* RAW — **пре-масштаба**, поэтому `s = C + (p − C)·1.07`, `C = (7.5, −148.0, 18.5)`;
* перевод в локальные координаты корня PRIMUM: `local = (−s.x, s.z, −s.y)`;
* поворот бокса: `yaw` вокруг Y (0/90 для осевых, произвольный для круглого RING), у лестниц ещё
  `pitch = −atan(подъём/забег)`.

Правила по классам:

| Класс | Отбор | Слияние |
|---|---|---|
| WALK | коллекция `20_PLATFORMS`, только 9 имён (деки/платформы; парапеты и riser'ы отброшены) | — |
| STAIR | объекты `…- STAIR - STEPS` / `*_STAIR_*`, **без** перил/ограждений/подступенков-деталей; группа = марш | один бокс на марш; `pitch` по **габариту** (bbox), а не по средним (средние занижают из-за площадок) |
| WALL | `10_WALLS` (+ `PART_*`, `ADM_SHELL`); толщина/длина из локального bbox объекта (OBB) | по линии стены: spans объединяются при зазоре ≤ 0.30 м → **окна залиты**, двери (зазор > 0.3) остаются проёмами; высота = объединённый диапазон Z |
| FLOOR | `05_FLOOR` (без `STAIR`) — плиты и перекрытия | — |
| ROOF | `50_ROOF` (+ `PARAPET`) | по дому: одна коробка на дом |
| **Пропуск** | `30_WINDOWS`, `40_INTERIOR`, `60_DECOR`, `20_ENTRANCE` (у дверей свои коллайдеры), маркеры | |

## 4. Как пересобрать

```powershell
# 1) Blender: боксы из RAW-блендов -> CSV (~23 мин на 23 чанка)
& 'W:\SteamLibrary\steamapps\common\Blender\blender.exe' -b --factory-startup `
  --python 'docs\world\primum_city\04_COLLIDERS\tools\colliders_v2.py'

# 2) (при правке WALK/лестниц) пересобрать только их и слить CSV
& 'W:\...\blender.exe' -b --factory-startup `
  --python 'docs\world\primum_city\04_COLLIDERS\tools\colliders_fix_walk_stairs.py'
#    -> _analysis\colliders_fix.csv, влить в colliders_v2.csv (удалив старые WALK/STAIR)
```

В Unity — меню **`ProjectC → World → PRIMUM → Коллайдеры`**:

| Пункт | Что делает |
|---|---|
| *собрать всё (WALK+STAIR+WALL+FLOOR+ROOF)* | снести `PRIMUM_COLLIDERS` и собрать заново (идемпотентно) |
| *только низ+лестницы (WALK+STAIR)* | то же, но только два класса (быстрый шаг проверки) |
| *отчёт (без изменений)* | сколько строк в CSV и групп получится |
| *удалить все* | снести узел |
| *проверить покрытие (лучи)* | 1200 лучей вниз по пятну города, разбивка попаданий |

Скрипт: `Assets/_Project/Editor/Primum/PrimumCollidersBuilder.cs`.

## 6. Что осталось / известно

* **Интерьеры не покрыты** (мебель, шкафы) — по решению «мелочь не плодить».
* **Крыши — по одному боксу на дом**: скатные крыши аппроксимированы, на коньке возможен «ступенька».
* **`S1_GLD` (дворцы) — 38 стен на 5 зданий**: геометрия сильно слилась по линиям; если при осмотре
  будут «проходы сквозь стены» — поднять `LINE_QUANT`/уменьшить `MERGE_GAP` и пересобрать.
* **`S9_RING` — 3 крыши**: у круглых домов крыши лежат не в `50_ROOF`; при необходимости добавить
  отбор по имени.
* **Лестницы есть не во всех чанках** (15 чанков без `STAIR`) — в этих моделях внутренних лестниц нет
  либо они в интерьерных коллекциях.
* **`PAVING` MeshCollider выключен** (39 166 верт., non-convex) — если понадобится точная брусчатка,
  включить обратно (он лежит в префабе BASE и переживёт только до пересохранения префаба).
* Двери: у префабов свои коллайдеры (4 432), рама — триггер `E`, полотно блокирует.
