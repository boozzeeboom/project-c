## 2. Где это в сцене

```
WorldRoot_0_0
├── PRIMUM                 ← город (инстанс PRIMUM_CITY.prefab) — НЕ ТРОГАЕМ
├── PRIMUM_DOORS           ← 2 161 префаб двери
└── PRIMUM_COLLIDERS       ← ✅ трансформ = трансформ PRIMUM (едет с ребейзом)
    └── <чанк>/
        ├── PLATFORM_<имя>     ← 9 отдельных MeshCollider'ов (BASE)
        ├── WALL               ← один GameObject, сотни BoxCollider (осевые)
        ├── FLOOR / ROOF
        └── STAIR              ← группы по (yaw,pitch): GameObject с поворотом + боксы
```

**Почему СОСЕД корня города, а не ребёнок:** всё, что добавлялось внутрь префаб-инстанса `PRIMUM`,
терялось при пересохранении префаба (так пропали `SLAB3` и старый `PRIMUM/COLLIDERS`). Корень
коллайдеров копирует трансформ `PRIMUM` и висит под `WorldRoot_0_0` → ребейз мира везёт физику
вместе с городом. Если корень города сдвинут — пересобрать (одно меню).

## 3. Откуда геометрия и как считается

Источник — **исходная (несклеенная)** геометрия `PRIMUM_chunks_RAW/*.blend` (23 чанка). Из склеенного
по материалу меша боксы получить нельзя: он охватывает чанк целиком.

* RAW — **пре-масштаба**, поэтому `s = C + (p − C)·1.07`, `C = (7.5, −148.0, 18.5)`;
* перевод в локальные координаты корня PRIMUM: `local = (−s.x, s.z, −s.y)`;
* повороты: `yaw` вокруг Y (0/90 у осевых), у лестниц ещё `pitch = −atan(подъём/забег)`.

Правила отбора:

| Класс | Отбор | Особенности |
|---|---|---|
| PLATFORM | объекты `DECK_*`, `PLATFORM_L*` из `20_PLATFORMS` | геометрия выгружается в `platforms.obj`, в Unity — `MeshCollider` (вырезы под лестницы) |
| STAIR | `…- STAIR - STEPS`, `*_STAIR_*`, без перил/ограждений; группа = марш | `pitch` по **габариту** (bbox), а не по средним (средние занижают из-за площадок) |
| WALL | `10_WALLS` (+ `PART_*`, `ADM_SHELL`) | отсев «косяков» (тонкие < 0.35 и короткие < 0.85); спаны = `[min,max]` по оси стены; **перемычки, начинающиеся выше пола + 1 м, в слиянии НЕ участвуют** → окна заливаются подоконными кусками, дверные проёмы остаются |
| FLOOR | `05_FLOOR` (без `STAIR`) | плита = бокс |
| ROOF | `50_ROOF` (+ `PARAPET`) | по дому; группы только из парапетов отбрасываются |
| **Пропуск** | `30_WINDOWS`, `40_INTERIOR`, `60_DECOR`, `20_ENTRANCE` (двери — свои коллайдеры), маркеры | |

## 4. Как пересобрать

```powershell
# 1) платформы -> platforms.obj (~10 c)
& 'W:\...\blender.exe' -b --factory-startup `
  --python 'docs\world\primum_city\04_COLLIDERS\tools\platforms_export.py'

# 2) боксы остальных классов -> colliders_v3.csv (~14 мин на 23 чанка)
& 'W:\...\blender.exe' -b --factory-startup `
  --python 'docs\world\primum_city\04_COLLIDERS\tools\colliders_v3.py'
#    (быстрый прогон одного чанка:  $env:COLL_CHUNKS="TRD-N")
```

В Unity — меню **`ProjectC → World → PRIMUM → Коллайдеры`**:

| Пункт | Что делает |
|---|---|
| *собрать всё* | снести `PRIMUM_COLLIDERS` и собрать заново (идемпотентно): CSV + 9 `MeshCollider` платформ |
| *только низ+лестницы* | то же, но только `STAIR` из CSV + платформы |
| *отчёт* | сколько строк/групп получится (без изменений) |
| *удалить все* | снести узел |
| *проверить покрытие (лучи)* | 1 200 лучей вниз по пятну города, разбивка попаданий |

Скрипт Unity: `Assets/_Project/Editor/Primum/PrimumCollidersBuilder.cs`.
Данные: `colliders_v3.csv` (7 154 строки) + `platforms.obj` (9 объектов, 215 вершин).
Меши платформ при сборке сохраняются как ассеты `Assets/_Project/Prefabs/City/Colliders/PM_PLATFORM_<имя>.asset`.

## 6. Что осталось / известно

* **Интерьеры** (мебель, шкафы) не покрыты — по решению «мелочь не плодить».
* **Крыши — один бокс на дом**: скатные крыши аппроксимированы, на коньке возможна ступенька.
* **`S9_RING` — 3 крыши** (у круглых домов крыши не в `50_ROOF`).
* **Лестницы есть не во всех чанках**: 15 чанков без внутренних лестниц (в моделях их нет или они в
  интерьерных коллекциях).
* **`PAVING` MeshCollider** (39 166 верт.) **выключен** — низ города держат 9 платформ + рельеф.
  Если понадобится точная брусчатка на склонах — включить обратно.
* Двери: у префабов свои коллайдеры (рама — триггер `E`, полотно блокирует).
