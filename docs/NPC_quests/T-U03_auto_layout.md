# T-U03: Авто-лейаут

**Дата:** 2026-07-22
**Файл:** `QuestNodeGraphView.cs`
**Слой:** 0 — Фундамент
**Зависит от:** T-U01, T-U02

## Что сделано

### Убраны фиксированные колонки
Было: `COL1_X=0, COL2_X=360, COL3_X=720, COL4_X=1100` — жёсткие позиции, добавление/удаление stage ломало граф.
Стало: `ApplyAutoLayout(allNodes, rootNode)` вычисляет позиции динамически.

### BFS-лейаут
- Строит adjacency map по рёбрам графа
- BFS от корневой ноды (QuestRoot) — каждая нода получает слой (layer)
- Слои = колонки, ноды в слое — вертикально с `V_GAP=40f`
- Колонки сдвигаются на `NODE_W + H_GAP` (240 + 60 = 300px)
- Орфаны (ноды без рёбер) размещаются в последний слой

### Сохранение ручных позиций
- `_nodePositions` словарь (из T-U01) проверяется перед авто-лейаутом
- Если нода была вручную перемещена — позиция сохраняется
- Новые ноды всегда получают авто-позицию

### Константы
- `V_GAP = 40f` — вертикальный отступ между нодами
- `H_GAP = 60f` — горизонтальный отступ между слоями
- `NODE_W = 240f` — ширина ноды
