### Ошибки и уроки

- **E1. Пики по origin, не по вершинам.** FBX-«кластеры» асимметричны: вершина East в 1399 м от origin. Правило: только max-vertex world XYZ.
- **E2. Завышенные σ → кламп-плато.** Контролить метрикой `clamped%` (финал 0.00–0.02%).
- **E3. Потолки `min(h,ceiling)`.** Выглядит как выгрызенные плато. Открытость делать fitted-склонами, дистанцией цепей, штампом оригинала.
- **E4. Неверный порядок операций** (снятие → доводка → досыпка = двойной учёт). Порядок: база → герои → цепи → доводка вершин → отроги (только вверх) → clamp.
- **E5. `GetHeight` возвращает мировые единицы** (`size.y`), не нормаль. Чуть не сорвал верификацию.
- **E6. Текстуры в `*Textures*` — мимо git** (`.gitignore:17`). Перенёс `MoveAsset` (GUID сохранены) в `Materials/World/Terrain/`.
- **Удачный приём:** точечный scoop через `GetHeights/SetHeights` по bbox вместо полной регенерации (ферма 0_2: 1923→1627 за секунды).
- **Метрика приёмки:** скан ВСЕХ объектов Y<2600 (7519 шт) на `gap<0`, а не 11 ручных точек — только он нашёл платформу «Основная часть» (644×640 м, была зарыта на 118 м).
