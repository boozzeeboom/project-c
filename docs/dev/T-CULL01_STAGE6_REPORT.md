## 2. Что сделано

### 2.1. `Assets/_Project/Scripts/World/VisibilityDirector.cs` (новый)

- **Хостинг:** авто-бутстрап на скрытый `ViewDistanceRuntime` (как бюджеты), только Play Mode,
  выключатель `AutoBootstrap`. Без `SetActive`, без `Camera.main`, без prefab/сцены.
- **Иерархия групп** (1 000 групп в игре): мир → чанк (район `PRIMUM/*`, ферма, спутник) → дом;
  отдельные классы `Doors`, `Ruins`, `Farm`, `Satellite`, `Ship`, `Interior` (`Int_*` heavy-корабля),
  `Lamps`, `Misc`. У каждой группы — владелец видимости и теней.
- **Мультикамерный union:** Game, активна, без RT, far ≥ 50, `cullingMask & слой мира (10)`, и камера
  дотягивается до якоря хотя бы одного чанка (`ReachesWorld`). Публичный API: `WorldCameras`,
  `TryGetNearestCameraDistance`.
- **Политика MVP:** под-пиксельный culling. Рендерер направляемой группы гасится `forceRenderingOff`,
  если его диаметр на экране < **2 px во всех камерах union**, и возвращается выше 2.24 px
  (гистерезис **12 %**), тик **3 Гц**. Видимую геометрию не трогает (объект < 2 px не читается).
- **FO-safe:** у участника хранится только смещение центра bounds **относительно живого `WorldRoot_0_0`**
  и габарит (инвариант к переносу); мировая точка = `WorldRoot.position + offset` каждый тик.
  Сброс кэша смещений + немедленный пересчёт: смена `frameGeneration` (success), скачок `WorldRoot`
  без смены `frameGeneration` (rollback/внешний перенос); скачок камеры > 50 м — немедленный пересчёт.
- **Провайдеры:** реестр по обнаружению (без правки бюджетов). Директор работает и без них.
- **Диагностика:** маркер профайлера `VisibilityDirector.Tick`, статистика тиков, отчёт камер
  (`+`/причина исключения), групп, провайдеров, пересечений владения.

## 9. Что осталось

1. **Решение пользователя:** двойное владение тенями ферм (`CityShadowBudget` + `ShadowBudget`) —
   оставить или передать фермы одному бюджету.
2. **Визуальная приёмка:** гашение < 2 px ферм/спутников и возврат на 2.24 px — за пользователем.
3. Перевод бюджетов на единый `VisibilityDirector.WorldCameras` (сейчас у каждого свой набор камер) —
   рефакторинг, только после согласования.
4. Пик тика 1.08 мс на массовом переключении (спавн/телепорт) — при необходимости разбить тик на
   несколько кадров; среднее в бюджете.
5. Политики для дверей/руин/интерьеров/кораблей не включались (наблюдение) — по брифу Kill-порядка
   они первыми урезаются, и их владение уже занято.
6. `WorldCamera` в рантайме нет — участие в union не проверено живьём (правило есть).
7. Stage 7 (HLOD/L1/L2) — следующий этап, не начинался.
