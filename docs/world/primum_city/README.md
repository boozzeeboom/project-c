## 1. Задача

В проект приходит готовый авторский город PRIMUM: 18 FBX-чанков, **147 715 мешей, 4 491 172 треугольника,
329.8 МБ**, координаты глобальные, центр города ≈ 2 × 2 км, поверхность на отметке ≈ 0…67 м внутри своей
модели. Нужно встроить его в мир так, чтобы:

* редактор оставался рабочим (сейчас инстанс города в сцене = 148 178 трансформов и «тупняк»);
* рантайм укладывался в существующую архитектуру мира (сцены, ViewDistance, Floating Origin, сеть);
* город было удобно развивать (кварталы, интерьеры, геймплей) без переделки каждый раз.

## 4. Принципы решения (кратко)

1. **Город = блоки + LOD, а не «один префаб в сцене».** Целевая зернистость: **20–60 блоков**
   (меши по материалам + коллайдеры), интерьеры — отдельными префабами по требованию.
2. **Резать по объектам, а не по сценам.** Отдельная сцена не спасает редактор (объекты те же), а стоит
   правок лоадера, серверного трекинга, FO-каталога и выгрузки в главном меню.
3. **Статикой — бесплатно.** Меши + коллайдеры без `NetworkObject`/`Rigidbody` = «простой контент»:
   положить под `WorldRoot_0_0`, каталог не нужен, rebase везёт сам.
4. **Слои — поименно.** Один слой на группу контента: сейчас **`PRIMUM`**, дальше `FARMS` и т. п.
   Слои — только для скрытия/диагностики; видимость камер и матрица физики проверяются отдельно.
5. **Всё измеряем.** Каждая фаза закрывается числами (объекты, рендереры, draw calls, треугольники),
   а Play Mode и F8/F9 прогоняет **пользователь** (агент Play Mode не запускает — `AGENTS.md`).

## 7. Глоссарий

* **Блок** — пространственная группа города (квартал/участок улицы) ~100–300 м, единица объединения,
  коллайдера и LOD.
* **L0/L1/L2** — кольца дальности: 0–3 / 3–12 / 12–80 км (калибруются под пресеты ViewDistance).
* **HLOD** — запечённый в редакторе упрощённый меш блока (1 меш на квартал) для среднего кольца.
* **Импостор** — предрендеренный билборд-силуэт города + квад ночных огней для дальнего кольца.
* **FO-гейт (09S)** — проверка старта Host: у каждого `NetworkObject` в загруженных сценах должен быть
  маркер, запись в `GlobalMotionPilotSceneCatalog` и сходящийся digest.
* **Рабочая сцена** — сцена только для редактирования (`Scenes/Test/…`), **не** входящая в билд.
