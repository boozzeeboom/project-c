# T-CHAR-UVRB — алгоритм переразвёртки UV и перепечки текстуры AI-персонажей

> Статус: реализовано, прогнано на `PC_Char_City_LowerCraftsman_APOSE_v02` (headless Blender 5.2.3 LTS).
> Визуальная проверка в Unity / на модели — **NOT RUN** (делает пользователь).

## 1. Проблема

Генератор (Tripo, `model_version v3.0`) отдаёт персонажа с атласом, нарезанным автоматическим
чартером: в исходнике `LowerCraftsman` — **211 островов** с рваными «воронеечными» краями
(1 оболочка, 643 657 треугольников, 321 852 вершины, текстура 2048²). Текстуру невозможно
читать/править руками, швы проходят через лицо и кисти.

Наивный пайплайн «Smart UV Project → bake» на такой геометрии **хуже исходника**:
(измерено `exp_smart_uv.py`, angle 66°)

| вариант | островов | из них < 50 граней |
|---|---|---|
| исходный UV Tripo | 211 | 50 |
| Smart UV по оригинальному мешу | **5 966** | 5 572 |
| Smart UV по сглаженному прокси (200 итераций) | 1 562 | 1 409 |

Причина: Smart UV режет по скачкам нормалей, а меш генератора — шумная плотная поверхность
(складки, «вокселизация»), поэтому каждая морщина становится границей острова.

## 2. Исследование

> Живой веб-поиск в этой сессии недоступен (нет инструмента поиска). Ниже — опора на
> устоявшуюся литературу по параметризации и документацию Blender; все выводы для нашего
> меша подтверждены численными прогонами (раздел 4), а не цитатами.

Принципы, которые взяты в алгоритм:

- **Чартинг отдельно от параметризации** — классическая схема (Garland et al. 2001
  *Hierarchical Face Clustering*; Sander et al. 2003 *Multi-Chart Geometry Images*;
  Zhou et al. 2004 *Iso-charts*; библиотека xatlas): сначала разбить поверхность на
  крупные почти-развёртываемые чарты, затем каждый разложить на плоскость.
- **Чарт обязан быть топологическим диском** (характеристика Эйлера χ = V − E + F = 1).
  LSCM (Lévy 2002), ABF++ (Sheffer 2005) и SLIM (Rabinovich 2017) корректны только для диска;
  цилиндр (χ = 0: рукав, штанина) раскладывается с огромным искажением или «кругом».
- **Минимизация растяжения вместо конформности**: конформные LSCM/ABF сохраняют углы, но
  сильно меняют масштаб на больших изогнутых чартах; SLIM (в Blender — `Unwrap` →
  `Minimum Stretch`) балансирует углы и площадь → равномерная плотность текселей.
- **Перепечка на том же меше по двум UV-слоям** (Cycles Bake, тип Emit; исходная текстура
  читается через UV Map-узел со старым слоем, запись — в новый слой): нет ray-cast, cage,
  extrusion и связанных с ними артефактов «Selected to Active».
- **Суперсэмплинг + Extend margin**: печь в 2× разрешении и уменьшать (антиалиасинг
  ресэмплинга), а пустое пространство заполнять продолжением края острова (mip-bleeding).

Документация Blender: Manual → *UV → Unwrap / Smart UV Project / Pack Islands*,
*Render → Cycles → Baking*.

## 3. Алгоритм (`Tools/Blender/CharacterRebake/rebake_character.py`)

1. **Импорт** `.fbx`/`.glb`, объединение мешей (общий UV-слой переименовывается в `UV_src`).
2. **Сварка** дублей вершин (`--weld 1e-5`). UV хранятся на углах граней, поэтому не теряются,
   а связность поверхности восстанавливается (иначе старые швы Tripo перейдут в новые чарты).
3. **Сегментация на сглаженном прокси.** Копия меша с той же топологией сглаживается
   (`Smooth`, factor 0.5, `--smooth-iters 600`) — уходят складки, остаётся форма тела.
   По прокси делается **Smart UV Project** (`--angle 66`), границы его островов
   (`Seams from Islands`) переносятся на оригинал по индексам рёбер (топология идентична).
4. **Слияние мелких островов с контролем топологии.** Остров площадью меньше
   `--min-island-frac` (0.4 % площади) присоединяется к соседу с самой длинной общей границей,
   **только если результат остаётся диском**: χ(i∪j) = χi + χj − (V∩ − E∩) = 1
   (V∩/E∩ — общие вершины/рёбра; формула включений-исключений для подкомплексов).
5. **Сглаживание границ** мажоритарным фильтром (`--border-smooth 12`): грань переходит к острову,
   которому принадлежат ≥ 2 её соседа — срезает «пилу» по краям.
6. **Принудительная дисковость.** Для каждого острова считается χ; острова с χ ≠ 1
   (цилиндры, замкнутые оболочки) режутся плоскостью, содержащей их главную ось (PCA) —
   рукав → две полуцилиндрические полосы. После разреза — сглаживание и повторное слияние крошки
   (с тем же запретом на не-диск). До 8 проходов.
7. **Развёртка** по швам итоговых островов на **оригинальной** геометрии:
   `Unwrap MINIMUM_STRETCH` (SLIM), затем `Average Islands Scale` и `Pack Islands`
   (CONCAVE, с поворотом, зазор `--margin-px 8`).
8. **Печка**: Cycles, `EMIT`, `UV_src → исходная BaseColor (Cubic) → Emission`, цель — новая
   картинка на `UV_bake`, `--supersample 2`, `--samples 4`, `Extend`-bleed `--bleed-px 16`.
9. **Финализация**: удалить `UV_src`, один материал (Principled + новая текстура),
   экспорт тем же форматом (FBX→FBX без вшитых текстур, `path_mode=STRIP`; GLB→GLB),
   оригинал не трогается.
10. **QA**: метрики до/после (острова, длина швов, покрытие UV, перевёрнутые грани, CV плотности
    текселей), число оставшихся не-дисков, **round-trip** — реимпорт результата и сверка
    габаритов/граней/UV/арматуры/текстуры.

|---|---|---|---|---|---|
| слияние без контроля топологии + ABF | 44 | 0.428 | 569 | 0.499 | большие цилиндры, сильное искажение масштаба |

Компромисс: покрытие UV ниже исходного (0.43 против 0.64), т. е. при том же разрешении
линейная плотность текселей в среднем ≈ на 18 % ниже, зато она равномерна (CV 0.10 против 0.23),
а острова крупные и читаемые. При необходимости — `--res 4096`.

## 5. Известные ограничения

- Голова/лицо делится на 3–4 острова (Smart UV режет по направлению нормалей). Ручная доводка:
  `--save-blend <путь>` сохраняет рабочий `.blend` со швами — поправить швы, перепечь.
- Острова < 50 граней (16 шт.) — фрагменты у не-manifold рёбер меша генератора (40 шт.)
  и острова, которые нельзя слить без потери дисковости.
- Меш не децимируется: плотность сетки остаётся исходной (643 тыс. треугольников).
- Перепечка = ресэмплинг: детали мельче текселя новой развёртки сглаживаются.
- Для `.glb` с ригом (`*_Rigged`) путь реализован (join + экспорт GLB), но **не прогонялся**.
