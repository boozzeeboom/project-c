# LLM-прогоны — архив экспериментов

> Здесь лежат **сырые логи, промпты, конфиги и анализы** LLM-игр. Формат — по одной папке на эксперимент, чтобы потом строить графики прогресса.

## Структура

```
llm_runs/
  README.md
  YYYY-MM-DD_<эксперимент>/
    README.md          — что проверяли, гипотеза, итог
    PROMPT_DESIGN.md   — разбор промпта до игры
    prompt.txt         — фактический ZERO_DOCTRINE / system prompt
    config.json        — модель, режим, лимит, число игр
    matches/           — сырые JSON логов (по одной игре)
    analysis.md        — анализ после игр
    summary.json       — машинно-читаемая сводка (для графиков)
```

## Как строить прогресс

- `progression.json` — сводный машинно-читаемый файл по всем Zero-прогонам.
- `summary.json` каждого прогона содержит: win/draw/loss, moves, center ticks, supports, line deaths, fallbacks, ошибки.
- Для графиков: собирать `summary.json` из всех папок, ось X — дата/номер прогона, оси Y — winrate, средняя длина, center ticks, доля убийств Линейного.
- Не смешивать разные режимы/лимиты в одном графике без пометки.
