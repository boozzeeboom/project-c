### 7.2. Двери: главный потребитель бюджета дома

- Двери **не клеятся** (§4.2): анимация створок, триггер-коллайдер, per-renderer `forceRenderingOff`.
- Двери — **инстансы 12 префабов** `PM_DOOR_*` / `PM_ADM_*`; слой **10** у корня и всех детей, `static=0`.
- Дистанция: `layerCullDistances[10]=150` **под GRD мёртв**; реально режет `VisibilityDirector`: off **150 м**,
  on **135 м**, тик 0.33 с, одно свойство `forceRenderingOff`. На площади гасятся 4 697 из 5 493; в кадре 419;
  >150 м — **0** (контроль 2 633).
- Корень `PRIMUM_DOORS/<имя>` должен **совпадать с именем HLOD-блока**, иначе дверь привяжется только по дистанции.
- `Door Layer → Apply` обязателен на чистом клоне (префабы дверей вне git).
- Формула на дом: **1–7 дверей** (среднее 4.65); >10 — проверить дубли.

### 7.3. Математика масштаба: 5 домов vs 250 домов

Экстраполяция по одному дому (`_evidence/02_FARMS.md` §5), калибровка — 576 домов = 1 949 DC города при P1,
т.е. **3.4 DC/дом** в текущей гранулярности [E]:

| Величина | 1 дом | **5 домов** | 25 домов | **250 домов** |
|---|---:|---:|---:|---:|
| Двери (инстансы / MR / слоты) | 4.65 / 9.8 / 24 | **23 / 49 / 121** | 116 / 245 / 603 | **1 163 / 2 454 / 6 036** |
| Коллайдеры (двери + дом) | 31 | **157** | 784 | **7 841** |
| Визуальные слоты | 3.1 | **16** | 78 | 783 |
| Entry теней | 2.3 | **11** | 57 | **565** |
| **DC в кадре** | 3.4 | **≈17** | ≈85 | **≈850** |
| Дверных рендереров в кадре (150 м) | ≤2 | ≤10 | ≤50 | ≤300 (потолок города 419) |

**Где предел.** Один кластер — **≤150–200 DC** (≈**45–60 домов**) и **≤600 entry теней**. 250 домов = **≈850 DC**:
это **43 % всего города** и **36 % бюджета кадра** — это уже отдельный «город/район», а не ферма.

**Правило:** ферма >60 домов **не строится одним объектом** — она нарезается на блоки по **25–45 домов**
(как поставка города: 18–45 домов на чанк), каждый блок — отдельный HLOD L1-меш, свой `PRIMUM_DOORS/<блок>`,
свои entry теней и свой бюджет света.

### 7.4. Правила слияния для домов/ферм

| ✅ Так | ❌ Не так |
|---|---|
| Клеить по `(группа × материал)`; ферма = 99 мешей на 2 фермы | «1 меш на ферму/все фермы»: экономит ≤280 DC, но тащит **1.27 M тр. в каждом кадре** |
| Cap **60 000 верт./меш**, `mergeSubMeshes=false`, `RecalculateBounds()` | Меш >65 535 верт. без UInt32-индекса |
| Материалов ≤8 на юнит; ≤12 на дом (город: 49 материалов на 576 домов) | Уникальный материал на дом (+2 DC/объект) |
| Двери/коллайдеры/свет — отдельно, не клеить | Клеить створки/`DoorController` (потеря анимации/физики) |
| Дом/квартал — батчами (чанк/блок × материал), как сейчас | Дробление по дому (B2: 330 батчей против 160, DC растёт) или ячейки 10–30 м (+16…+47 % слотов) |
| Интерьеры — отдельным мешем/слоем | Интерьеры в общем батче (78.6 % тр. города не видны) |

### 7.5. Коллайдеры: правила

- **Примитивы `BoxCollider`**, не один concave-меш и не per-triangle: sphere-vs-box дешевле sphere-vs-triangles.
- Мин. размер объекта **0.25 м** (меньше — пропуск), мин. толщина бокса **0.5 м** по каждой оси,
  расширение **вниз** (верх заподлицо) — лечит проваливание кораблей.
- Исключения по имени: `BOLT, SCREW, RIVET, NUT, WASHER, PIN, WIRE, CABLE, HOSE, PIPE, RAIL, LAMP, LIGHT, GLOW,
  GLASS, WINDOW, DECAL, MARKER, REFERENCE, TRIGGER, VOLUME, LOD*`.
- Круглые бары (`PIPE, REBAR, TUBE`) — `CapsuleCollider` по длинной оси (если длина ≥ 2 диаметров).
- Кривые меши — slab-нарезка `sliceStep 1.0 м`, `sliceAdaptTol 0.05 м`; полости не заливаются.
- Слияние соседних боксов `mergeGap 0.1 м`; иерархия — отдельный `<Root>_Colliders/<здание>`,
  **не на узлах FBX** (переимпорт снесёт).
- `MeshCollider` — редко, `convex=false`, cooking: `CookForFasterSimulation + EnableMeshCleaning +
  WeldColocatedVertices + UseFastMidphase`. `convex=true` на статике — запрещён.
- На дом: **≈21 бокс** (≤30 — норма); на 250 домов — ≈7 841 бокс, но **не число боксов** тормозит зоны:
  `OuterCommZone/MarketZone` с `OverlapSphere(r=1000, маска ~0)` давали **82.93 мс и 136.6 КБ GC** на полл.
  Перед масштабированием ферм — сузить `pollLayerMask` зон (вариант A из `25092026/02_FARM_COLLIDERS.md`).

### 7.6. Тени: не добавить третьего владельца

| Компонент | Кого берёт | Порог | Тик |
|---|---|---|---|
| `CityShadowBudget` | все `Renderer` (кроме слоя 10, кораблей, уже `Off`) | off **200** / on **180 м** | 0.33 с |
| `ShadowBudget` | только дети корня `Primum_farms` (`farRootNames`) | off **60** / on **50 м** | 0.33 с |

**Известный дефект:** в полосе **60–200 м** от камеры два компонента гоняют `shadowCastingMode` навстречу
друг другу (~3 Гц мигание теней ферм). Не исправлено с Stage 6. **Не усугублять:** не добавлять третьего писателя,
не расширять `farRootNames` на корни, которые уже покрывает `CityShadowBudget`; для новой фермы либо
имя корня ≠ `Primum_farms` (тогда только `CDB`, 200/180), либо один владелец + отдельный слой.
`QualitySettings.shadowDistance`/каскады не трогать — URP их игнорирует.

### 7.8. Решения и что осталось (после 2026-11-01)

- **Дома строим как раньше — блочной поставкой** (`блок × материал`), префабов домов не вводим. Дробление по дому (B2)
  даёт 330 батчей против 160 и рост DC; текущие 3.4 DC/дом — уже оптимум. Новые поселения — блоками по 25–45 домов.
- **HLOD — по факту наполнения:** готов ряд/квартал → `Bake All Blocks + L2` + determinism check; не после каждого ассета.
- **Фермы — без отдельных слоёв по группам:** всё под `Primum_farms` (+ `Primum_farms_DOORS`, слой 10 у дверей).
- **FBX вне git, префабы можно вести в git** (как сейчас); если префабы станут тяжёлыми — решим позже (точечное исключение
  из `.gitignore` с одобрения).
- **Канон масштаба — 1.06** (решение 2026-11-01).
- **HLOD ферм/спутников/руин не существует** (бейкер знает только `PRIMUM`): при ×100 фермы дают L0-DC на всех дистанциях —
  первый кандидат на расширение бейкера, когда наберётся ряд ферм.
- **Мёртвые ассеты-ловушки:** `Prefabs/City/Colliders/PRIMUM_BC_*.prefab` (18 файлов, **12 111** боксов) и
  `Colliders/Houses/PM_HOUSE_*` (100 мешей) — **0 ссылок** в сценах/префабах. Это НЕ текущий пайплайн;
  живые коллайдеры — inline `HOUSE_*_BOX` в сцене (12 299 BoxCollider).
- **Мерж города живёт в scene-overrides** (174 001 запись, 34.3 МБ, 54.6 % файла сцены) — reimport/Apply сносит;
  `PRIMUM_CITY.prefab` вне git. Для ×100 нужен детерминированный тул + манифест (рецепт — `J_CITY_FARMS_MERGE_RECIPE.md`).
