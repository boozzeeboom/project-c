# Свободный осмотр: панорама и зум

**Дата:** 2026-09-17
**Статус:** ✅ Реализовано
**Код:** `ChartWindow` (секция WORLD-MAP-PAN)

## 1. Режимы

- **Слежение** (по умолчанию): центр = своя позиция, статус `СЛЕДОМ`.
- **Свободно**: центр = запомненная точка, статус `СВОБОДНО`. Своя точка
  при этом едет по карте (проекция, не центр) — видно, куда уплыл.

Переход: любое таскание автоматически роняет в свободный режим;
кнопка «◎ Слежение» возвращает (текст вкл/выкл отражает состояние).

## 2. Управление

- Таскание ЛКМ: клик (<3px) vs drag различаются по движению (Down/Move/Up).
  В режиме постановки метки таскания нет — только точные клики.
- Колесо мыши: зум ×1.2 / ÷1.2 в тех же пределах 0.5–64 м/пкс.
- Клик без движения — старое поведение (метка/циркуль/постановка).

## 3. Реализация

- `GetCenter()`: слежение+есть свой → свой; иначе свободная точка.
  Все проекции (сетка, порты, треки, метки, циркуль, подписи, клики) идут
  через центр — FO-безопасно как раньше.
- Дельта экрана в мировую — обратной формулой проекции (поворот
  ортонормален, транспонируем): те же `north`/`k`, что в `MapToWorld`.
- Своя точка и циркуль в свободном режиме проецируются, а не центрируются.
