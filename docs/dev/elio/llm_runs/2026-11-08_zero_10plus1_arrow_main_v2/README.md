# 2026-11-08 v2 — DeepSeek за Нулей: исправленный список действий

## Что изменено относительно v1

v1 показал 47 поддержек и **0 ходов**: для Нулей список действий был отсортирован «поддержки первыми», и в топ-16 не попало ни одного хода. Это ошибка harness’а.

В v2:

- Для Нулей показываются **до 10 ходов** (приоритет — ворота/«Ц») и **до 6 поддержек**.
- В промпт добавлен жёсткий запрет support-only:
  - поддержка не заменяет гонку за «Ц»;
  - каждый второй ход должен двигать фигуру к «Ц» или блокировать угрозу;
  - не повторять уже стоящую поддержку.
