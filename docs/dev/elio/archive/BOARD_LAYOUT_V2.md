# Эльо — геометрия доски по наброску (v2)

> Статус: анализ/документация. Источник: набросок пользователя + выжимка правил.  
> Макет: `prototype_v2.html`.

## 1. Что изображено на наброске

- **Три гексагональных поля** расположены «лепестками» вокруг общего центра: одно сверху, два снизу (влево/вправо).
- Поля не соприкасаются: между ними остаются **три треугольных зазора**.
- В центре — **треугольное основание**, образованное внутренними сторонами трёх полей.
- В каждом гексе — сетка клеток (на наброске — схематичная, похожа на квадратную).
- Спорные земли — **треугольники по 3 клетки** в зазорах между парами полей.

## 2. Формализация

### 2.1. Поля
- Каждое поле — правильный шестиугольник (flat-top), повёрнутый к центру.
- Центры полей лежат на окружности радиуса `R = 220` через 120°.
- Размер поля (радиус описанной окружности) `HEX_SIZE = 120`; клетка `CELL_SIZE = 40`.
- Внутренняя вершина поля (ближайшая к центру) находится на расстоянии `R - HEX_SIZE = 100` от центра — это создаёт зазор для основания и спорных земель.
- Внутри — 17 клеток (по выжимке). В макете v2 для наглядности 19 гексагональных клеток; точную раскладку 17 нужно утвердить.
- **Ключевая клетка** — центральная клетка поля; её занятость определяет атакуемость поля.

### 2.2. Основание
- Равносторонний треугольник в центре, вписан в окружность радиуса `baseR = 70` (меньше внутренней вершины поля 100, чтобы не перекрывать поля).
- Предлагаемая раскладка: **4 клетки** — 1 центральная + 3 клетки поддержки (по одной к каждому полю).
- Центральная клетка — цель удержания (3 хода).
- Клетки поддержки — для фигур поддержки, защищающих центральную фигуру.

### 2.3. Спорные земли
- Три треугольника, по одному в каждом зазоре между парами полей.
- Каждый — **3 клетки** (по выжимке).
- Нейтральная зона: нули, входя на неё, временно принимают сторону соседнего поля.

### 2.4. Связи
- Поля соединяются с основанием через клетки поддержки/спорные земли.
- Спорные земли соединяют пары полей между собой.
- Возможные маршруты: поле → спорная земля → поле; поле → основание; основание → поле.

## 3. Что это меняет в правилах

1. **Защита основания** становится геометрически осмысленной: 3 клетки поддержки окружают центральную клетку, и фигуры на них защищают центр.
2. **Спорные земли** — естественные «коридоры» для нулей: 3 клетки на каждый зазор, чтобы принять сторону соседа.
3. **Атака полей** привязана к ключевой клетке поля: пока она не занята противником, поле защищено.
4. **Три лепестка** дают симметрию 120°: у каждой фракции равные условия.

## 4. Открытые вопросы

1. **Форма клеток внутри поля**: гексагональная (улей) или квадратная (как на наброске)?
2. **Раскладка 17 клеток**: 1+6+10? 1+6+6+4? 4+5+4+4? Нужна точная схема.
3. **Количество клеток основания**: 1 центральная + 3 поддержки (предложение) или иное?
4. **Количество клеток в спорной земле**: 3 (по выжимке) — как именно расположены (в ряд/треугольником)?
5. **Соединения**: какие клетки считаются соседними между полем и основанием/спорной землёй?
