# T-FO07F — Сдвиг штормовых ячеек вместе с миром

Date: 2026-09-13.

## Аудит

`StormCellDirector`: ячейки — чистые данные `WorldPosition` (дрейф от ветра,
push в шейдер `StormCellPosId`, дебаг-маркеры). Эмиттеры/шейдер — мировые
координаты. Без сдвига шторма остаются в старых координатах на десятки
километров, пока ветер их не унесёт (долго). `WindManager` читает live-позиции
кораблей — кэша нет. Карта/компас в gameplay-коде не найдены (только HUD).

## Решение (best-effort, скопом с тем же паттерном)

- `StormCellDirector.ApplyRebaseTranslation`: сдвиг всех ячеек + сразу
  `PushStormCellsToShader()`, возвращает число.
- Slice (сервер, оба пути): маркер `StormShifted(cells=N)`.
- Второй клиент: директор-синглтон работает на всех пирах — сдвиг
  в `OnRebaseShiftMessage` (счётчик `storms=` в `ClientShiftApplied`).

## Границы

- Дебаг-маркеры перестраиваются из ячеек следующим кадром сами.
- Параметры шторма (сила/шум/контраст) — не координаты, не трогаем.
- Проверка возможна только при активных штормовых ячейках в момент F8.

## Проверка

1. Compile: `refresh_unity` + `read_console` — 0 errors, 0 CS.
2. Play Mode (user): F8 при шторме → `StormShifted(cells>0)`, шторм рядом,
   а не в старых координатах.
