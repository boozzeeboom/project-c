# Zero-доктрина v3 — что изменилось относительно v2

> Дата: 2026-11-09. Файлы: `zero_doctrine_v3.txt` (промпт для арены). Применяется к прому `2026-11-09_v3_zero3models_arrow15`.
> Обновление v1.4: в актуальном промпте «3 круга» заменено на «3 следующих собственных хода Нулей»; описанные ниже старые прогоны выполнены по прежним правилам.

## Зачем v3

Измеренные проблемы v2:

| Проблема | Доказательство |
|---|---|
| Модель болтает фигуру туда-обратно | Beam: 69 % осцилляций (45/65 ходов); 752/757 — 9 из 10 ходов |
| Не доходит до центра | Beam: 6 center ticks за 10 игр (8 игр — 0); DeepSeek v2.1: 5 из 6 игр — 0 center ticks |
| Приоритет «защити Линейного» выше «займи Ц» | приводил к погоне за недостижимым Линейным вместо гонки за центром (713/715/718) |
| Нет победы по лимиту в промпте | системный промпт говорит «Ц занят на лимите → победа», доктрина — только «3 круга» |
| Модель не знает дальности Нулей | в промпте описаны только военные типы; модель ошибается в расстояниях |

## Изменения в промпте (v2 → v3)

1. **Приоритеты переставлены:** «Займи Ц» — №1; Линейный — только «если рядом твой нуль»; добавлено «если рядом нет — НЕ гонись».
2. **Победа по лимиту:** «стоять на Ц в последнем ходу лимита → победа».
3. **Новый блок ДВИЖЕНИЕ:** дальности Капитан-Линейный/Диверсант 1, Свободный 3, Курьер 4, Инженер 2; Скиталец 1 и не поддерживает; аура Инженера щит 1; для 15 фигур — план расстановки 5 скитальцев.
4. **Новый блок ЖЁСТКИЕ ЗАПРЕТЫ:** не возвращаться на прежнюю клетку, не двигать одну фигуру 3 хода подряд, не повторять поддержку, не поддерживать до занятого Ц.
5. **Список действий:** промпт предупреждает, что возвраты уже отфильтрованы.
6. Взяты мелкие правки v2: Бомбардир **и Корвет** прыгают; план требует указать целевую клетку к «Ц».

## Изменения в арене (harness)

`selectActions(acts, faction, state)` при `ELIO_V3=1` для Нулей:

- **убирает немедленные возвраты** (назад на клетку, с которой фигура только что ушла) — кроме клеток «Ц»/ворот (возврат на Ц — это прогресс);
- **убирает 3-е движение одной фигуры подряд** (последние 3 хода Нулей одной фигурой);
- если после фильтра не осталось ходов — оставляет исходный список (чтобы у модели всегда был ход).

Фильтр **включается только по `ELIO_V3=1`** — v2-прогоны остаются неизменными для честного сравнения.

## Что НЕ вошло в v3 (deferred)

- H1 — LLM сам выбирает `passTo` (сейчас случайный; для Arrow+Main неактуально).
- H2 — выбор Нулями направления цикла (неактуально для Arrow).
- H7 — сортировка поддержек по угрозе Линейному (требует threat-расчёта в арене).
- H9/H10 — парсер support/Hardening, raw-логи уже частично сделаны (raw+plan пишутся).
- Пересчёт «Аура Инженера» и AI-скора (A1–A5) — отдельная задача.
