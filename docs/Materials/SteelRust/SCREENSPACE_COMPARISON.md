# Screen-space состаривание — сравнение 3 версий (исследование, кода нет)

Date: 2026-10-04. Статус: RESEARCH ONLY. Решения «ставить» нет.

## Контекст

Основной путь SteelRust v1 — object-space шум + vertex colors (сделан,
`ProjectC/ProceduralSteel`). Вопрос: нужен ли сверху общий screen-space
слой (ржавчина/пыль/кавити по глубине+нормалям с камеры, как Global Dirt).

## Версия A. Собственный Cavity Renderer Feature (open-source за основу)

- Кандидаты: `malyawka/URP-ScreenSpaceCavity` (MIT), `federicocasares/cavifree`
  (Blender-кавити для URP/HDRP, Volume-интеграция).
- Как работает: fullscreen pass по `_CameraDepthTexture` +
  `_CameraNormalsTexture`, ridge/valley → маска → затемнение/ржавчина.
- Плюсы: ноль работы художника, «настоящие» стыки без bake, один слайдер
  на всю сцену; исходники открыты, можно вырезать только маску и подать её
  в наши материалы как глобальный uniform.
- Минусы: +1 fullscreen pass в Forward (наш рендер уже несёт EdgeDetection +
  VolumetricClouds); артефакты на силуэтах/тонкой геометрии; нужны корректные
  DepthNormals у всех кастомных шейдеров (у ProceduralSteel прохода
  DepthNormalsOnly пока нет — см. TODO-DEPTHNORMALS); эффект экранный —
  «плавает» при движении камеры, для ржавчины это заметнее, чем для AO.
- Оценка: 1–2 дня (интеграция + борьба с EdgeDetection за порядок проходов).

## Версия B. Asset Store: Global Dirt / Cavity Shader / Rust-Dust Layers

- Global Dirt: Volume + Renderer Feature, материалы не трогает, пресеты
  Dry/Grimy/Abandoned. Но: металл/ржавчина требуют **Deferred**, у нас Forward —
  половина фич не заведётся; платный; внешний dependency в MMO-клиенте.
- Cavity Shader: Edges and Contours — screen-space кавити под URP 14+/Unity 6,
  работает в Forward. Платный, закрывает только подсветку кромок, не ржавчину.
- Rust, Dust and Layers Shader Pack — слоёные материалы, но требует UV
  и свои шейдеры вместо наших; противоречит цели «свой пайплайн без текстур».
- Вердикт: не рекомендую ни один. Чужие шейдеры вместо своих = потеря
  контроля над FO-safe, батчингом и стилем ради сомнительной экономии.

## Версия C. Ничего сверху (текущий v1) + общий слой пыли позже своим кодом

- Сейчас: ProceduralSteel самодостаточен. Стыки — R-канал, кромки — G-канал.
- Позже (когда будет 3+ материалов): один свой легковесный fullscreen или,
  лучше, per-material слой пыли (A-канал + facing-up, уже заложен в договор
  каналов) — без новых проходов вообще.
- Плюсы: ноль зависимостей, ноль конфликтов с EdgeDetection, FO-safe
  по построению. Минусы: стыки только там, где художник запёк/докрасил.
