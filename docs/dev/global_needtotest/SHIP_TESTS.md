# Global Need-To-Test — реестр ручных тестов (долгосрочный)

> Каталог: `docs/dev/global_needtotest/`. Назначение: все проверки, которые агенту
> нельзя выполнить самому (Play Mode, два клиента, мод-клиент) — их проводит пользователь.
> Правило: каждый кодовый тикет (`T-SHIP-FIX*` и далее) дописывает сюда свои кейсы.
> Формат кейса: `[ ]` + шаги + ожидание + приоритет. Закрытые: `[x]` + дата + кем.
> Приоритеты: 🔴 блокер (регресс = откат), 🟡 критический (эксплойт/десинхрон), 🟢 рутина.
