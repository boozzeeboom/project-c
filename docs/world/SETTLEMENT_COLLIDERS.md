# 📦 Settlement Colliders — коллайдеры поселений в один клик

**Скрипт:** `Assets/_Project/Editor/BuildSettlementColliders.cs`
**Меню:** `Tools → ProjectC → Build Settlement Colliders...`
**Для чего:** фермы и другие FBX-поселения (сотни–тысячи мешей), где нужно, чтобы
и игрок ходил, и корабли садились/не проваливались.

## Как использовать

1. Закинь FBX на сцену под корень мировой сцены (как обычно).
2. Выдели **корень** поселения в Hierarchy
   (например `Project-C_primum_farm_x_1_2_GameReady`).
3. Меню: **Tools → ProjectC → Build Settlement Colliders...**
4. Нажми **Dry Run** — в Console увидишь, сколько боксов будет создано и сколько мелочи отсеяно.
   Если structural-геометрия попала в пропущенные — ослабь `Мин. размер` / почисть список исключений.
5. Нажми **Build**. Появится иерархия `<Root>_Colliders/<Здание>/BC_xxxx_<имя>` со статичными BoxCollider'ами.
6. Сохрани сцену. Готово.

Повторный **Build** сносит `<Root>_Colliders` и строит заново (идемпотентно).
Переимпорт FBX коллайдеры не ломает — они живут отдельно в сцене.

## Параметры

| Параметр | Дефолт | Что делает |
|---|---|---|
| Мин. размер меша (м) | `0.25` | Меши с max стороной world AABB меньше этого пропускаются (болты, мелочь). |
| Мин. толщина бокса (м) | `0.5` | Тонкие оси расширяются до этого значения **вниз** (топ заподлицо с визуалом). Лечит проваливание кораблей сквозь палубы (класс ошибки `MD2_Deck_Blockout`). |
| Исключить по имени | список | Подстроки имён через запятую (болты, провода, лампы, LOD'ы...). Регистр не важен. |
| Группировать по зданиям | вкл | Раскладка боксов по прямым детям корня (обычно отдельное здание/двор). |
| Пропускать выключенные | вкл | Выключенные в иерархии меши коллайдеров не получают. |
| Чинить тонкие боксы | вкл | Заодно утолщает pre-existing тонкие BoxCollider внутри **выбранного корня** (город не затрагивается). |

## Почему Box на каждый меш, а не один общий меш

- Игрок (`CharacterController`) стоит на любом статичном коллайдере — боксов достаточно.
- Корабль (`Rigidbody`, Continuous) со статичными боксами дружит из коробки;
  тонкие/плоские `MeshCollider` (особенно `convex`) для палуб — бумага, сквозь неё туннелят.
- Боксы не требуют варки (быстрый Build даже на 2к мешей), PhysX broadphase их жуёт легко.
- Лестницы: бокс на ступеньку, ходьба проверяется в Play Mode; если ступеньки слишком мелкие —
  подними `Мин. размер` так, чтобы они не отсеялись, либо убери их имена из исключений.

## Floating origin

Коллайдеры — обычные дети корня, хранят только локальные `center/size`. Сдвиг мира везёт их
бесплатно. Проверка: F8 → `runtimeRebase.Completed` + всё на месте, F9 → возврат.
