# Персист журнала между сессиями

**Дата:** 2026-09-17
**Статус:** ✅ Реализовано
**Код:** `ChartJournalStore.cs` (NEW), `ChartTrackRecorder` + `ChartMarkManager` (load/save)

## 1. Файл

Один атомарный per-clientId JSON, как остальные сейвы игрока:
`Application.persistentDataPath/Chart/chart_<clientId>.json`
(рядом с `Character/character_<id>.json`, `Skills/slot_bindings_<id>.json`).
Внутри: треки + метки + `nextMarkId` + офсет сдвига `rb*` на момент сейва.

## 2. Перенос через сдвиг мира (PERSIST01)

Зеркалит `ShipPositionServer.ShiftWrapperByOffset`: при загрузке
`pos = file − fileOffset + liveCumulative`.
- Новая сессия (кумулятив 0): позиции возвращаются в исходный кадр.
- Та же сессия после F8: остаются на месте.
- Без сдвигов: добавка нулевая, поведение прежнее.

## 3. Когда грузим/пишем

- Загрузка — ленивая, один раз (нужен слушающий NGO ради `LocalClientId`).
- Треки — грязный автосейв каждые 30 с + на выходе из игры.
- Метки — сразу при add/remove (их мало, файл не жалко).
- Пишет рекордер (`SaveJournal` — треки и метки разом), менеджер его дёргает.

## 4. Разрывы телепортов

Отрисовка рвёт ломаную при скачке >5 км или паузе >30 мин —
респаун/вход/загрузка не тянут линию через всю карту.
