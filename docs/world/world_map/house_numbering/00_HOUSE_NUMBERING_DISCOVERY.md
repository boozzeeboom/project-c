# House Numbering & Discovery — дизайн-нота (WorldScene_0_0)

**Дата:** 2026-11-06  
**Скоуп:** только `WorldScene_0_0` (Примум + 5 ферм Примума).  
**Статус:** анализ/план, кода нет.

## 1. Цель

- Пронумеровать дома Примума автоматически (по дверям), чтобы каждый дом имел уникальный ID вида `N<чанк>-<номер дома>` (пример: `RES_S2_101 → Дом N2-101`).
- Показывать номера на карте (клавиша M) **только для домов, к которым игрок подошёл** (радиус 15 м), и **запоминать** открытые дома per-player (как треки).
- Расставить «таблички» (пока плавающий текст, одна коллекция `HOUSE_SIGNS`, чтобы потом заменить 3D-ассетом).
- Фермы Примума (`0_0…0_4`) показывать на карте как «Фермерское угодье х-х».

## 2. Источники данных в сцене

### 2.1. Дома Примума
- Корень города: `WorldRoot_0_0/PRIMUM` (~26 чанков: `S1_GLD`, `S2_TRD`, …).
- Двери: `WorldRoot_0_0/PRIMUM_DOORS/<чанк>/` — каждый ребёнок = `DoorController` (слой 10).
- Имя двери содержит идентификатор дома:
  - Внешние: `RES_BIG_01_DOOR_JAMB_…`, `GLD_CREATION_01_DOOR_LEAF…`, `RES_BIG_01_OBS_DOOR…`
  - Внутренние: `…_INT_DOOR_…` / `…_IN_DOOR_…`
  - Суффиксы `_TQ`, `_VER`, `_BALC…` — варианты одной двери, не отдельные дома.

**Правило идентификации дома:**
1. Отрезать суффикс от `_DOOR` / `_IN_DOOR` / `_INT_DOOR`.
2. Отрезать trailing `_TQ/_VER/_BALC…` (regex `^(.*?_\d+)`).
3. Итог = `houseId` (например `RES_S2_101`, `GLD_CREATION_01`).

**Внешние входы** = двери, в имени которых нет `IN_DOOR`/`INT_DOOR`.  
**Центроид дома** = среднее позиций внешних дверей (или всех дверей, если внешних нет).

### 2.2. Фермы Примума
- `WorldRoot_0_0/Primum_farms` содержит:
  - `Средняя 0_0` (ферма 0_0)
  - `Ферма Примума 0_1`
  - `Ферма Примума 0_4`
- Отдельные корни:
  - `Ферма Примума 0_2`
  - `Ферма Примума 0_3`
- Все 5 ферм (`0_0…0_4`) показывать на карте как «Фермерское угодье х-х» (позиция = Transform фермы).

## 3. Нумерация домов

- **Чанк-префикс**: `S2_TRD → N2` (буква/номер чанка).
- **Номер дома**: существующий номер из имени (`101`, `204`…) **или** последовательный 1..N внутри чанка, если номера нет.
- **Итоговый ID**: `N2-101`, `N9-204` и т.д. — уникален в пределах города.
- Фермы: `Farm 0_0`, `Farm 0_1`, … (или «Фермерское угодье 0-0»).

## 4. Discovery (runtime, per-player)

- Компонент `HouseDiscovery` (аналог `ChartTrackRecorder`/`ChartMarkManager`):
  - `DontDestroyOnLoad`, per-player, сохранение в файл, Floating Origin hook (`ApplyRebaseTranslation`).
  - Хранит список открытых домов: `houseId`, `number`, `worldPos`, `utcSeconds`.
- **Триггер открытия**: игрок в радиусе **15 м** от центроида дома (проверка периодически, ~1–2 с). Дополнительно — открытие внешней двери.
- Запись в список + автосейв (как метки).

## 5. Карта (ChartWindow)

- При открытии (M) собрать открытые дома из `HouseDiscovery` + фермы (всегда видны? или тоже discovery? — предлагаю фермы всегда, так как это «поселения»).
- Рисовать кружок + номер (`N2-101`) по аналогии с портами (слой «Дома»).
- При зуме точки могут сливаться — ок, не приоритет.
- Floating Origin: позиции берутся живыми (как треки), кэшей нет.

## 6. Таблички (плавающий текст)

- Одна коллекция `HOUSE_SIGNS` под корнем города/чанка (чтобы ехала со сдвигом).
- Для каждого дома — один `GameObject` с `TextMeshPro` (плавающий текст) над центроидом внешних дверей (смещение вверх ~2 м).
- Имя GO: `HouseSign_N2-101`.
- Позже можно заменить на 3D-ассет (префаб) без изменения логики.

## 7. Риски

- Внутренние двери: фильтр по имени (`IN_DOOR`/`INT_DOOR`), но возможны ложные срабатывания при нестандартных именах. Нужен отчёт «осиротевших» домов.
- Нет отдельных домов-объектов: табличка ставится в координате двери, стена может быть рядом.
- Несколько входов: одна табличка на дом (главный вход = `DOOR_JAMB`/`OBS_DOOR`).
- Floating Origin: маркеры/таблички обязаны быть детьми корней сцен.
- Runtime-парсинг имён дверей при загрузке сцены — один раз, допустимо, но лучше Editor-утилита для создания `HouseMarker` GO.

## 8. Шаги реализации (без кода)

1. Создать `HouseMarker` (MonoBehaviour) + `HouseDiscovery` (DontDestroyOnLoad, save/load, rebase hook).
2. Editor-утилита (или runtime-парсинг): обойти `PRIMUM_DOORS`, сгруппировать двери по домам, создать `HouseMarker` GO + табличку (плавающий текст) под `HOUSE_SIGNS`.
3. Расширить `ChartWindow.OnChartPaint`: слой «Дома» + «Фермы».
4. Добавить discovery-проверку (15 м) в `HouseDiscovery.Update`.
5. Тест: подойти к дому → номер появляется на карте → сохраняется → после перезапуска остаётся.
