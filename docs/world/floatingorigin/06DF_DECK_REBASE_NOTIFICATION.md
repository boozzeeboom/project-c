# T-FO06DF — Уведомление палуб о сдвиге (сброс кулдауна пере-регистрации)

Date: 2026-09-13

## Аудит (read-only, без нового лога)

`ShipDeckNav.LateUpdate` — дрейф-детектор: при уходе `ShipRoot` дальше
`_navFrameSeparation/2` (5000/2) по XZ — `Unregister()` + очередь
пере-регистрации (1/кадр) + `_nextReregistrationTime = Time.time + 30f`.

Из `ф8_7.txt`: после `Completed` все 20 палуб штатно перерегистрировались
в новых координатах (`Registered at (520.67, -58.27, 80.30)` и т.д.).
Механизм работает, чинить нечего.

## Дыра

30-секундный кулдаун после пере-регистрации: повторный F8 в пределах 30с
дрейф-детектор обнаружит (`delta` огромна), но строка
`if (Time.time < _nextReregistrationTime) return;` проглотит сдвиг —
палубы молча останутся на stale-навмеше в старых координатах, NPC-экипаж
на палубах встанет. В логе это будет выглядеть как «всё ок» (ни ошибок,
ни маркеров), поэтому чиним заранее, а не по факту.

## Решение (минимальное, без изменения штатного пути)

- `ShipDeckNav.NotifyWorldRebased()` (static, только сервер): всем живым
  заспавненным инстансам `_nextReregistrationTime = 0`. Сами инстансы не
  трогаем — Unregister + очередь 1/кадр выполняет дрейф-детектор.
- Slice вызывает в обоих путях (успех после сдвига камеры; rollback после
  возврата): маркер `runtimeRebase.DecksNotified(decks=N)`. Идемпотентно,
  флага не требует.

## Границы

- Бюджет 1 AddNavMeshData/кадр и 6–50мс на регистрацию не меняем.
- Окно без навмеша (~20+ кадров на 20 палуб, transient agent warnings)
  сохраняется штатно; синхронный rebuild всех палуб в транзакции —
  отдельный gate (T-FO06BH и далее), здесь только гарантия от проглатывания.
- Пассажиры/прокси (NpcBrain) — отдельный трек.

## Проверка

1. Compile: `refresh_unity` + `read_console` — 0 errors, 0 CS.
2. Play Mode (user): F8 → `DecksNotified(decks=20)`; затем второй F8
   в пределах 30с (после отхода от origin) → палубы снова `Registered at`
   в новых координатах, без залипания на stale.

## Верификация 2026-09-13 (ф8_8.txt) — PASS

Полная цепочка до `Completed`, `DecksNotified(decks=20)`, все 20 палуб
`Registered at` в сдвинутых координатах (напр. `Сильфида (520.68, -58.31, 80.29)`),
игрок стабильно `(56.004, -57.835, 64.000)`, телепортов после — 0, ошибок — 0.
T-FO06DF закрыт полностью.
